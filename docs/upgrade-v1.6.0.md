# CargoFit v1.6.0 升级记录

发布日期：2026-11-28

## 核心升级项

### 1. D07（P1）：瓦楞纸箱 McKee 理论抗压与 3D 实际叠压压溃风险估算
- 新增 `lib/packing/bct-estimator.ts`：
  - 基于简式 McKee 公式（$BCT = 5.87 \times ECT \times \sqrt{h \times Z}$）支持 4 档瓦楞纸板（单瓦楞 C 楞 / 双瓦楞 BC 楞 / 加强双瓦楞 AB 楞 / 重型三瓦楞 AAA 楞）与 3 档储运温湿度环境（干燥短途 / 标准海运 30 天 / 高湿长途海运 60 天+）。
  - 自顶向下按真实 3D 接触投影面积比例逐层传递上层货箱重量，精确算出当前方案中每个 SKU 实际承受的最大上压载荷（kg），与安全允许堆码上压对比给出安全/预警/压溃风险评估。
  - 显式声明理论值不能替代纸箱厂实测空箱抗压仪（BCT）数据。

### 2. D19（P2）：双策略全维度工程并排对比卡
- 新增 `lib/packing/plan-comparator.ts`：
  - 自动并排对比「现场易执行（Practical）」与「高密度参考（Maximum）」两套真实求解方案的 7 项核心工程指标（装入总箱数、体积利用率、总货重、托盘数、左右重心偏移、建议充气袋数、柜尾纵向空隙），高亮胜出项并支持一键导出对比报告 CSV。

### 3. 质量与回归保障
- 新增 `lib/packing/v16-features.test.ts`（3 项单元测试），保持全部既有测试零回归。
