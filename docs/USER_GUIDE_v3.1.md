# CargoFit 装柜智算 v3.1.0 使用教程与工程操作手册

## 1. 快速开始（六大角色工作台）

进入主工作台（`/app`）后，可根据岗位切换六大角色预设，系统会自动聚焦当前角色高频模块、减少无关干扰：

- **快速测算（外贸业务员）**：输入箱规/重量/数量或粘贴 Excel，3 秒得出装柜套数与运费 ROI。
- **专业装柜（物流计划员）**：启用多柜联合优化、已装柜锁定保护、多目的地 LIFO 卸货顺序与三轴半挂车轴荷校核。
- **包装工程（产品/包装工程师）**：使用反向包装尺寸优化、6 级包装 BOM、智能托盘/8 零件木箱设计、10 类异形件嵌套、CAD/3D 模型预处理与 2×2 工程热力图。
- **现场执行（仓库装柜人员）**：一键生成 `/crew` 现场端分享包，支持扫码核销、防超扫、异常拍照与 100×150mm 热敏标签打印。
- **企业管理（管理层）**：审批状态机（草稿→待审→批准→签发）、不可变审计日志、跨版本 Diff 与持续校准闭环。
- **开发者中心（IT 与集成人员）**：查看 `cargo-fit-api-v3.1` 契约、在线运行 API 输出三维坐标 JSON、接入 TypeScript SDK 或 MCP Server。

## 2. 四种计算模式与多目标优化

1. **极速计算（1–3s）**：外贸快速询价。
2. **标准计算（3–15s）**：日常装柜，默认启用 Beam Search + BRKGA + SA + LNS 混合求解。
3. **深度优化（15–60s）**：复杂混装与多箱套装订单。
4. **极限搜索（自定义预算）**：支持实时进度、暂停/继续与随机种子复现。
5. **多目标权重**：可按需调节 6 维权重（最大装载量、最少柜数、最低运费、最少托盘、装载稳定性、现场便利性）并保存个人偏好；**所有物理硬约束（零碰撞、零越界、承重、套装完整、门洞净空）均强制锁定，不可通过权重绕过**。

## 3. 工程安全与「未核验」红线原则

- 当缺少纸箱厂实验室实测 ECT/BCT 抗压数据、木箱铭牌静/动载资料、车辆真实轴距/皮重或绑带额定破断力（LC）时，系统会显式标注 **「未核验」**，严禁将其等同于工程安全认证。
- 危险品（IMDG）规则库提供确定性隔离提示，正式海运出运须由具备资质的危品合规专员复核。

## 4. API 与 MCP Server 集成

- **API Schema**：`cargo-fit-api-v3.1`（向后兼容 `cargo-fit-api-v1.8` / `cargo-fit-api-v1.2`）。
- **MCP Server**：运行 `npm run build:mcp` 生成 `server-build/cargofit-mcp.mjs`，可直接挂载至支持 MCP 协议的 AI Agent，通过真实确定性求解引擎返回精确三维坐标与工程审计结果。
