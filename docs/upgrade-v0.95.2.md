# CargoFit v0.95.2 — BoxStudio 编码生成器与回归修复

依据用户的 `cargofit_v0_95_1.html`、两张标注截图及 `cargofit_pro_prd_dev_spec.md`，本轮完成编码迁移与第一里程碑的缺陷、公共组件收尾。后续物理规则和商业官网不在本轮标记为已交付。

## 编码迁移

核心来源为同一用户的 `guodongbuding66-spec/BoxStudio`：`src/codeGeneratorV72.js`、`src/codeGeneratorUiV72.js`、`src/pngPrintV70.js`。复用固定版本 `@bwip-js/generic@4.11.4`，将交互适配到现有 React 唛头工作台。

- Code 128 / 39 / 93、EAN-13 / 8、UPC-A、ITF-14、GS1-128、QR、Data Matrix、PDF417、Aztec。
- 毫米尺寸、内容校验、商品码自动补校验位、可读文字开关、白底静区与最小模块密度；二维码保留原生模块比例。
- 实时预览、SVG / 300 DPI PNG 下载、当前正唛或侧唛插入、更新选中编码、撤销及 JSON 备份。变量在插入时解析为当前 SKU 等实际值。
- 新编码保留可编辑参数，旧 Code 39 / QR 图层仍可读取。编码不会被自动缩小以塞进画板；覆盖静区或越过安全区时阻止应用及印刷图像导出，JSON 草稿仍可备份。
- PNG 同时计算 300 DPI 像素尺寸并写入 pHYs 元数据。条码在浏览器生成，不发送编码内容到服务器。

## 回归项目

| 项目 | 本轮变更 |
|---|---|
| 线框异常 | 按每块结构件的世界坐标生成实体边线，避免依赖带多材质组的三角线框；实体材质、UV 和求解包络保持原样。 |
| 查看器空白 | 主工作台、包装预览及方案查看器共用 ViewportRenderer；无 WebGL 或三维渲染异常时使用真实坐标降级视图。弹窗保持明确高度、筛选和播放。 |
| 默认演示报红 | 新演示采用 1200 × 2300 mm 宽托、1800 mm 货物限高、单站次及有限装卸路径搜索。双算法均完成 144 箱，重心进入建议区域，路径计算通过；不伪造缺失承重或运输固定资料。现有用户草稿不被替换。 |
| 只打托预警 | 录入时比较全部启用、适用包装的内部底面、货物限高和扣除新增支承件后的载荷；忽略零数量订单。 |
| 单位和三栏 | 整托可承上压改用内嵌 kg；三栏使用一致标题、默认折叠及等高网格。 |
| 整托基准清单 | 使用 ExcelDataGrid，默认严格合并同类托盘，可展开逐托、搜索、复制和导出原始行。合并行不伪造共同坐标。尺寸与底板类型增加分隔符。打印仍逐托列出。 |
| 标尺 | 文字轨道增加 10 px 外偏；保留物理测量边、刻度及坐标。 |
| 设计规范 | app/tokens.css、CompactConstraintTable 与现有 ExcelDataGrid / UnitInput / StatusBadge 共用语义角色。 |

## 验证与边界

12 类实际 SVG 加一份中文 QR 均以 300 DPI 栅格化，再由独立 ZXing-C++ 解码验证。UPC-A 扫描器返回等价的前导零 GTIN-13 表示，同时核对格式为 UPC-A；GS1 保持 AI 内容。此验证是数字图像解码，不是实物印刷等级认证。

完整回归、构建及线上界面验收在发布时另行核对。硬件 WebGL、实体扫码及未实际运行的设备视口不宣称通过。
