# v0.44.0 单托局部自动重排

日期：2026-10-19。基线 GitHub `0da52de4eed4a6d1cda487ea52d43c6d4db2bc26`，源树 `90f3de70a37a5b612e31055bf92772fbfd984f16`。

托内编辑新增可取消的自动重排预览。移走部分货物后，可只重新安排这一托的剩余纸箱，优先降低最高点，再缩小货物外包络占地；不重新生成整批托盘，不移动其他整托，也不自动借用订单余量。

## 完成内容

- 同时保留箱数、实物箱 ID、SKU、套号、套内序号、重量、包装库存及原有整托坐标。锁定箱体会固定其接触支撑链及同套全部组件，递归闭包后再搜索可移动货物。
- 托内原始轴向搜索，允许朝向先转换到局部坐标，候选再随整托四向转换回实际柜内位置。同步修复 180°／270° 整托下的三维拖动偏移，四个方向均使用同一逆变换。木箱内壁、实心支承、实际底座面板、原底面、悬跨、层数、承托比例与已填静载上限保持有效，未知资料继续未核验。
- 候选不超过原最高点，不能通过删箱或拆套降低高度。外壳固定的木箱仅可能降低内部货物最高点，外壳尺寸不变。普通托盘的降低最高点可能扩大货物占地，预览同时展示两项取舍。
- 每个有改进的完整候选重新经过整柜事务校验，其他整托的全部箱体状态逐项保持不变。失败候选整批拒绝，显示有限原因；无改进时不写历史，也不把有界搜索当作无解或全局最优证明。
- 后台工作线程运行；单托最多 160 箱、4 轮，4 秒后不再启动新轮次，10 秒任务预算超时终止。支持取消及忽略迟到消息。当前输入、任意整托或锁定变化会使旧预览失效。
- 先看前后最高点、整托总高、占地、固定与移动数，再写入托内编辑草稿；接入原有撤销／重做／放弃，最后采用更新清单、坐标、重心、静载、CSV、PDF 和备份。订单余量及包装库存不变，现场进度需要按新版本核对。

## 首阶段边界与后续

仅普通长方体箱规。异型件及组合模型、从订单余量自动补货、跨托联合重打、编辑托内支架和连续全局优化仍未完成。U07／011C 整体继续 PARTIAL。真实 GPU、多浏览器硬件及现场试装仍 PENDING，具体叉车操作继续 EXCLUDED。

阶段 011 已覆盖层型模板、明确长件承托、实心附件及单托既有纸箱重排的首阶段；后续自动实施转入阶段 012 木箱正式自动叠放，其结构资料缺失时仍要求底置。011 的复杂接触和跨托等深化继续保留在台账。
