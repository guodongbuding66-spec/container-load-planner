# v0.30.0 标称与保守尺寸双方案

基线：GitHub main 061567caa1b0ac4dacbd5511cc2a3ffcb713e037（v0.29.0）。日期：2026 年 10 月 16 日。

## 使用流程

1. 完成订单与装载配置，计算一份有效标称方案。
2. 打开“方案工具 → 装载优化 → 标称尺寸与保守尺寸对比”，选择 SKU。
3. 录入来源、批次、实测日期；可选输入实测三围。保守尺寸以标称与实测各轴较大值为基准，不因实测较小而缩小。
4. 选择每个尺寸的总增量，或两侧每面增量。每面 3 mm 表示该轴总加 6 mm。输入跟随长度单位显示，内部始终保存 mm。
5. 添加随箱附件：来源 ID、名称、三围总增量、每箱新增 kg。尺寸已包含在基准中、重量已包含在现有毛重中，分别勾选“已计入”。同一 SKU 的附件来源 ID 不得重复（忽略大小写和前后空格）。托盘／木箱自重继续由原包装设置计入一次。
6. 保存规则，重新计算标称方案，再点“计算保守方案并对比”。未完成数字、未保存规则、过期或计算中的主方案不能启动比较。

## 计算契约

- 标称货物的三围、重量和订单数量不被修改。偏差配置保存在 ProductInput.dimensionAllowance，正常主计算不应用此字段。
- 保守请求深复制主请求，各轴取 max(标称, 实测) + 公差总增量 + 尚未计入的附件尺寸；重量 = 现有毛重 + 尚未计入的附件重量。保护间隙独立保留，不当作加厚或重量。
- 原箱位复核保持每箱最小角点 XYZ 和朝向不变，换入保守三围与重量，复用完整快照校验。它不自动移动原货物；可能因新增重叠、层间穿透、门洞、重量、托内高度或承托而失败。
- 保守方案在独立 worker 中按相同策略、需求、经验率、数量上限和包装规则重新求解；支持直接装柜、单品容量、只打托和先打托再装柜。用户可停止，输入或主结果变化时销毁过期 worker。
- 重新排布是现有启发式结果，不保证最优，也不保证数量变化单调。不根据 CBM 比例虚构少装箱数或成功概率。
- 箱数、套数、重量、利用率、各 SKU 差异和远端／门洞尺寸余量来自当前快照。门洞余量仅是尺寸差，不代表转向、抬升或叉车可以通过。只打托查看坐标不冒充实际仓库墙壁余量。

## 异型与附件的边界

异型件或实体模型三围增加时，改用明确标记的外包络长方体，覆盖完整原包络和增量；不把增量暗中变成曲面或材料形变。关闭叠放并要求底置，保留显式允许朝向。外包络占位通过不能证明实际可落地面、支架、防滚或材料强度通过，承托保持未核验，并禁止生成 PDF／离线现场指导书。

本轮附件用于随箱外尺寸与单箱重量，不是独立可摆放的垫木／支架模型，不增加整柜绑扎、气袋或挡木算法；也不启用木箱框架叠放。

## 快照、恢复与导出

- 双方案各自保存 request、完整 plan、scenarioId、类型、来源指纹和引擎版本；切换指标、三视图、三维和坐标导出时使用同一完整快照。
- 规则随当前工作区／归档／本机草稿保存；旧产品无此字段时保持标称行为。
- 产品导入 CSV 的可选 dimensionAllowance 列是上述配置的 JSON，内部尺寸 mm、附件 kg，不受其它 CSV 录入单位影响。
- 坐标 CSV 在原有列末尾增加“尺寸方案ID、尺寸口径”，每条货物／托盘记录都带标记；不改变普通主方案 CSV。
- 独立“双方案与来源 JSON”包含来源与两份坐标，可恢复查看。恢复时验证来源指纹、两份派生输入与 scenarioId，再按各自输入重新验证坐标并重建统计，忽略文件中的旧指标；不替换当前订单或把保守坐标交给标称输入。
- 三维查看器与 PDF 页眉显示当前尺寸口径与方案 ID；受影响的异型代理不允许导出现场 PDF。
