# v0.42.0 实心落地支承件与累计静载

日期：2026-10-19。基线 GitHub `05e413b3be49185b932a60fb11cc16d8d3954940`，源树 `3f6a76e547d0ceef08dc03f467e98f20d97452ea`。

此前整柜垫木和支架只有禁占包络，货物不能放在其顶面。现在可在原附件记录中明确声明单件落地、实心平顶支承件，按真实长宽和厚度提供接触，并累计上方各层静载。原有附件默认继续保持非支承，不能因名称包含“垫木”而改变几何含义。

## 数据与实现

- 声明 `accessory.support={version:1,surface:"solid-rectangle",maxLoadKg:number|null}`。只支持实体 timber/bar/other，数量 1、装货前安装、Z 严格为 0；不接受悬空、与其他实体相交、充气袋、绑带或防潮附件。分散垫木须分行，不把空心支架或框架外包络当作实心面。共用已有最多 16 个区域。
- 上方静载上限不含支承件自重。null 是未知，0 是禁止承载；填入的数值即使缺来源也执行硬上限，缺额定值、来源或版本则报告未核验。静载按接触面积分配，传递所有上层箱重；不计算抗弯、刚度、地板局部压力或运输动态。
- 共享零重量支承锚点进入求解、统一校验、层级重建、编辑、最终优化、补货试放、诊断与恢复；不进入货物清单或套装数量。附件计划重量和实体容积沿用原记录各计一次，边界余量不裁掉计划重量，不因顶面被净空裁切而虚构可承托顶面。
- 长条箱预检使用这些实物接触面，保留两垫木间空隙；来源版本缺失仍未核验。既有承托面积、原底面、层数、总载重、整套回退及锁定箱位约束保持有效。
- 中英文设置与结果清单、绿色投影、五项复核、客户／离线 HTML、附件 CSV、坐标 CSV、PDF 和双策略备份保留同一声明。导出载荷结论用当前箱规重新检查；无完整当前产品资料时载荷留空、状态未核验。PDF 复核说明限定行数，完整说明保留在客户报告／工作区。

## 首阶段边界

仅直接装柜／单品容量使用固定落地支承件。预打托、只打托、底层铺托盘不接入该声明；切换时明确提示，可取消支承声明保留普通附件。托内或托盘连接垫木、叠垫木、任意框架／曲面／孔洞接触、自定义受力区和局部自动重排仍待实现。声明是用户提供的实物资料，不是实测或材料强度认证。具体叉车作业仍 EXCLUDED；真实 GPU／多浏览器硬件和现场试装仍 PENDING。

## 验证与发布

本阶段测试覆盖：未知与零额定、厚度和层级、累计上压、来源缺失、输入范围、浮空和重叠、顶面裁切、单品／拼柜、完整套装回退、锁定编辑／优化、两端垫木悬跨、普通承托面积不可放宽、补货、双策略备份、篡改恢复、CSV／HTML／分页 PDF 和中英文设置。新增 28 项核心回归与 2 项界面回归。最终 `npm run build:pages` 通过：1,073 项单元测试（85 文件）、21 项 HTML、TypeScript、lint 零错误（3 条既有警告）及 Next 静态生产构建。正式站验收与发布标识在实际完成后补入。
