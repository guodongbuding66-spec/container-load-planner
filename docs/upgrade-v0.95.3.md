# CargoFit v0.95.3 候选版 — 货物录入与工作台布局

本轮依据 `cargofit_pro_prd_dev_spec(1).md`，只处理第一里程碑内的货物表与配置页布局。此文记录代码范围和已观察的验证结果，不代表正式站已发布。

## 货物录入

- Step 3 使用共用 ExcelDataGrid：搜索 SKU、套装、订单行及客户批次，每页 25 行，吸顶表头、网格线、内部滚动及数值右对齐。
- 基本尺寸、箱数与套装信息保持横向对齐；方向、底置、层数等详细规则展开在对应 SKU 下方，不再把表格撑成超宽列。
- 复制和 Excel 导出始终包含全部源行及未显示的装载规则，不受当前搜索或分页限制。Excel 使用真实数值单元格，按当前录入单位输出；长度、重量、CBM 与整数字段分别设置显示精度，原始数值不作四舍五入。
- 数值无效时保留输入并阻止搜索、翻页、删除、切换规则区和打开会重置输入的编辑器；复制、导出及下一步仍受现有校验约束。待提交尺寸不能被当成已保存数据导出。
- 新增或删除行后清空搜索，不以重新挂载整张表的方式重置搜索。重回相同行数也不会恢复过期的搜索词。

## 页面布局

- Step 1–3 / 5–6 配置内容与操作条居中限宽 1200 px；Step 4 / 7 的检查画布使用可用宽度。
- 内部分区使用分割线，减去重复嵌套的面板边框；复用已有语义颜色、控件与圆角变量。
- 平板保留表格内部横向滚动；手机保留纵向字段布局与 44 px 输入/操作目标。
