# v0.41.0 长条箱承托限制接入求解与采用

日期：2026-10-19。基线 GitHub `509242d8cea9040628ad8b686169af25e5858a85`，源树 `97e4352f99629484f23924e8a39a1446ae44e5a8`。

此前预检能发现不符合支承带、悬跨和悬挑的位置，主求解和手动采用仍可能接受它们。现在资料完整、与当前箱规绑定且接触几何适用时，自动候选和统一箱位校验会拒绝这些明确失败；原有承托面积、上压、重量、层数与成套要求继续执行。

## 完成内容

共享实际接触检查用于单品／拼柜、铺底托盘候选、主三维和托内编辑、层型批量应用、最终优化采用、撤销／重做／最终采用及备份恢复。托盘以实测面板实体提供接触，不填实板缝。预打托对每一规格生成的完整候选复核实际底座与内壁偏移；失败时尝试后续规格，不拆散套装。修改失败整次回退，原方案和锁定整托保持不变。

来源、版本或任一上限缺失、箱规变化、未测底座和未知接触面仍未核验。面板通过仅表示符合输入几何限制；材料抗弯和运输强度保持未核验。设置、五项复核、面板、客户／离线报告及 PDF 使用相同说明。
