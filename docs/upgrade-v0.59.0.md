# v0.59.0 独立测量复核 PDF

日期：2026-10-23（Asia/Shanghai）。功能代码已发布，双站原生导出已实际操作；原件于同日环境恢复后归档，默认方案恢复与当前回归已随 v0.60.0 完成，版本分别记录。

## 已完成的功能

已保存测量增加“下载测量 PDF”。报告包含点击时的全部已保存记录，包括隐藏和历史记录；不依赖当前三维显隐、播放、隔离或剖切筛选，也不包含未保存的临时测量。点击时同步冻结记录、状态、方案范围、语言、单位和精度。

报告包含记录名称、当前／需重测状态、端点与轴向分量、原始毫米值、时间、来源箱托、保存的包络或规则实体参数，以及 X/Y、X/Z、Y/Z 三个快照线框投影。历史图使用记录内的原始几何并明确标记，不能当成当前箱位。每条记录独立起页，长内容可续页；英文普通单词优先完整换行，中文和超长编号可按字符续行。

导出采用独立懒加载和重复点击保护，失败可重试；不会修改装箱数据或保存的测量。面板卸载后不触发迟到的下载，下载对象地址随后释放。原有指导书的 PDF 组装器提取为共享模块，原有指导书功能保持原范围。

完整功能契约见 [015D](field-upgrades/015d-measurement-pdf.md)。
