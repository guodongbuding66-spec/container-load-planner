> **文档定位**：面向 AI 编程代理（AI Coding Agent）直接执行的端到端产品与工程开发规范（PRD + Technical Spec + UI Design System + QA Acceptance Matrix）。
>
> **基准版本**：`CargoFit v0.95.5`（线上环境：<https://container-load-planner.pages.dev/>，2026-11-25 实测基线）。
>
> **目标**：修复 `v0.95.5` 全部实测缺陷，补齐外贸业务、跟单与装柜现场的核心断层痛点，吸收全球主流装柜工具优势，建立企业级跨端 UI 规范，打造面向外贸实战的标杆级 Web 装柜工具。

> **执行原则**：本文档**不设任何人工工期/天数标注**，所有任务严格按模块依赖批次（Batch 0–4）与可自动化验证的验收标准（DoD）组织。

## 3. v0.95.5 实测缺陷修复规范（Batch 0 必改项）

以下 7 项均为 `2026-11-25` 对 `v0.95.5` 实测确认的新发现缺陷与跨端加固要求，须在开发新功能前全部修复清零。

### 3.1 P1 阻塞级缺陷

1. **FIX-01｜第 3 步门洞净宽/净高前置校验缺失**

   * **复现条件**：选择 `40HQ`（内宽 `2350 mm` / 内高 `2700 mm`，门宽 `2340 mm` / 门高 `2585 mm`），第 3 步录入外箱 `1200 × 2345 × 2345 mm`。

   * **当前问题**：仅校验是否超出柜内可用尺寸，未校验柜门洞净宽/净高，导致完全无预警放行。

   * **修复规范**：

     * 对所有封闭柜型（GP/HQ/RF/RH/厢式货车）维护独立字段 `doorWidthMm` 与 `doorHeightMm`（开顶柜 `OT` 允许顶吊时豁免门高限制，框架柜 `FR` 豁免门宽/门高限制）。

     * 第 3 步输入变更时，遍历该 SKU 所有允许朝向 `(l, w, h)`：若存在朝向能放入柜内，但**所有允许朝向均无法通过门洞**（即均满足 `w > doorWidthMm` 或 `h > doorHeightMm`），立即在顶部黄色预警条及该行下方展示明确提示：`超过柜门净尺寸（门宽 2340 × 门高 2585 mm），无法经尾门装入；如需斜入或顶吊请切换柜型/调整朝向`。

2. **FIX-02｜English 模式 1280px 宽度下顶部导航栏双行折行**

   * **复现条件**：切换至 `English` 模式，在约 `1280px` 视口下修改参数触发顶部状态胶囊 `Draft saved · Recalculation pending`。

   * **当前问题**：导航栏总宽溢出，`Tutorials`、`Help`、`中文 | English` 掉入第二行，破坏顶部视觉基线。

   * **修复规范**：

     * 顶部导航栏强制 `flex-wrap: nowrap`；状态胶囊缩短英文文案为 `Draft · Recalc`（Tooltip 展示完整说明），并设置 `max-width: 180px; overflow: hidden; text-overflow: ellipsis; white-space: nowrap`。

     * 低于 `1180px` 视口自动将次级入口（`Tutorials`、`Other tools`、`Help`）收纳入“更多”下拉菜单（详见第 5 节 UI 规范）。

### 3.2 P2 重要体验缺陷

3. **FIX-03｜English 模式第 3 步表格 `Color` 表头断字与 `Settings` 按钮图标裁切**

   * **当前问题**：表头 `Color` 折行成 `Colo` / `r`；`Cargo Settings` 列中的 `Settings` 按钮左侧图标间距过紧且略微裁切。

   * **修复规范**：所有表头强制 `white-space: nowrap`；`Color` 列设 `min-width: 64px`；`Settings` 按钮设 `min-width: 96px; padding: 0 10px; gap: 6px; flex-shrink: 0`；表格外层容器开启 `overflow-x: auto`，严禁通过压缩单元格宽度导致单词拆断。

4. **FIX-04｜English 模式第 4 步下拉框文案截断**

   * **当前问题**：`Loaded pallet orientation` 下拉框内 `Auto horizontal rotation` 被截断为 `Auto horizontal rota...`。

   * **修复规范**：将英文选项精简为 `Auto rotate (horiz.)`，并将该 `<select>` 最小宽度提升至 `200px`（桌面端自适应填满栅格列）。

5. **FIX-05｜第 3 步货物数量录入 `0` 缺少弱提示**

   * **当前问题**：负数 `-5` 有严格红框拦截并禁用导出，但数量填 `0` 时静默通过，用户易误判该 SKU 参与计算。

   * **修复规范**：保留 `qty === 0` 允许保存（便于临时剔除某 SKU 试算），但该行自动置灰（`opacity: 0.65`）并在数量框下方展示灰色弱提示标签：`数量为 0，本次跳过装柜` / `Qty 0 · Skipped`。

6. **FIX-06｜第 7 步清单表格中文长表头两行折行**

   * **当前问题**：“整托入柜与货物基准”表格中 `整托外部总高 mm`、`总重 kg / 托` 折行成两行导致表头参差不齐。

   * **修复规范**：采用双层语义表头规范——主标题单行（`整托总高`、`单托总重`）+ 次行小字单位（`mm`、`kg/托`，字号 `11px–12px`，`color: var(--text-muted)`），所有列统一高度。

### 3.3 P3 架构与文案完善项

7. **FIX-07｜英文大小写瑕疵、全局入口与功能可发现性**

   * 修正 Results 状态栏 `passed Independent validation` → `passed independent validation`。

   * 在顶部导航栏新增 **全局公/英制切换（`mm/kg` ↔ `in/lb`）** 与 **深/浅色主题切换（Light / Dark / System）**。

   * 在顶部 `方案工具` 下拉菜单中增加 `自定义建模工作台` 快捷入口（不再仅隐藏在第 3 步某一行货物的 `设置` 内部）。

   * 规划商业落地页路由分离（详见模块 M8）。

## 4. 核心增量功能模块深度开发规格（M1–M8）

### M1｜一键凑满柜与尾货补单推荐引擎（Gap-Fill Optimizer）

**业务价值**：外贸业务员促单利器——在当前装柜结果（如 40HQ 利用率 78%）基础上，自动计算剩余空间还能补装多少箱指定 SKU，直接生成发给客户的补单建议。

* **入口位置**：第 7 步结果页顶部操作条新增按钮 `一键凑满柜 / Fill Remaining Space`，点击展开右侧抽屉面板。

* **输入参数（TypeScript 接口）**：

```
export interface GapFillRequest {
  basePlanId: string;
  candidateSkuIds: string[];          // 用户勾选允许补货的 SKU（默认全选已有 SKU）
  strategy: 'max_volume' | 'max_value' | 'balanced_ratio';
  targetUtilizationPct?: number;      // 目标体积利用率上限，默认 95%
  respectMaxPayload: boolean;         // 严格遵守柜体/公路最大载重，默认 true
  respectCoGEnvelope: boolean;        // 补货后重心仍须处于安全区间，默认 true
  skuUnitPrices?: Record<string, number>; // 可选：填入 FOB 单价用于“产值最大化”策略
  minAddIncrement?: Record<string, number>; // 可选：最小起订增量（如按 10 箱倍数补单）
}

export interface GapFillSuggestion {
  skuId: string;
  currentQty: number;
  recommendedAddQty: number;
  newTotalQty: number;
  addedVolumeCbm: number;
  addedWeightKg: number;
  addedValueUsd?: number;
}

export interface GapFillResult {
  beforeVolumePct: number;
  afterVolumePct: number;
  beforeWeightPct: number;
  afterWeightPct: number;
  suggestions: GapFillSuggestion[];
  limitingFactor: 'volume' | 'weight' | 'cog' | 'door_clearance';
  previewPlan: ContainerPlan;         // 可一键“应用此补单方案”覆盖当前计划
}

```

* **算法约束**：

  1. 复用现有 3D 残余空间列表（Free Maximal Spaces），在固定已装货物不动（快速模式）或全局重排（高密度模式）下执行贪心 + 局部二分搜索。

  2. 若当前已触及载重上限（重货柜），立即返回 `limitingFactor: 'weight'` 并提示：“当前受限重瓶颈（已用 XX% 载重），建议补充轻抛低密度 SKU”。

  3. 提供一键按钮：`应用到装柜方案` 与 `复制给客户的补单话术（中/英文）`。

### M2｜托盘 + 散箱同柜混装模式（Hybrid Stuffing）与风车式排托（Pinwheel）

**业务价值**：解决工厂“重货打托、轻货散装塞顶/塞尾”及 20GP 标准 10 托/40HQ 21 托排布的高频刚需。

* **模式升级**：在第 1 步装载模式中，将 `先打托再装柜` 升级支持勾选子开关 `允许同柜混装散箱（托盘顶部 / 剩余空隙）`，或在每行 SKU 的包装列新增三态选择：`必须打托` / `直接散装` / `自动（优先打托，尾箱散装）`。

* **风车式排托（Pinwheel Pallet Layout）**：

  * 针对 `1200×1000 mm`（美标/工业托）与 `1200×800 mm`（欧标托），在柜内排托算法中启用纵横交错排列（如 20GP 内长 `5898 mm ×` 内宽 `2350 mm`：常规同向仅排 8–9 托，风车式 `1200+1000=2200 ≤ 2350` 可稳排 **10 托**；40HQ 可排 **20–21 托**）。

  * 校验条件：勾选“允许托盘旋转 90°（风车式排托）”时，同步提示“需使用四面进叉托盘（4-Way Entry Pallet）”。

* **混装排布规则**：

  1. Phase 1：先放置所有整托（优先靠前/底部，遵守静态上压与叉车通道）。

  2. Phase 2：提取两类可用散箱空间——① 满足 `allowLooseOnTop === true` 且未超整托剩余承压 `palletMaxTopLoadKg` 的托盘顶面空间；② 柜尾及托盘侧翼残余落地空间。

  3. Phase 3：将标记为 `直接散装` 或打托后剩余的尾箱（Tail Cartons）填入上述空间，并在 3D/2D 视图与装柜指导书中以不同边框样式区分“整托”与“散箱”。

### M3｜纸箱外箱尺寸反推与改箱增容优化器（Carton Fit Optimizer）

**业务价值**：面向外贸跟单与研发打样阶段——在纸箱定稿前，给出“微调外箱尺寸就能省下一大笔海运费”的量化方案。

* **入口位置**：`方案工具 → 装载优化 → 纸箱尺寸优化器`（及单品容量测算结果页快捷入口）。

* **两类核心计算模式**：

  1. **外箱微调灵敏度分析（Trim-to-Gain）**：输入当前单箱 `L × W × H`、允许微调范围（默认 `±30 mm` 步长 `5 mm`）与目标柜型（如 `40HQ`）。枚举邻域尺寸组合，输出 Top 5“最小改动、最大增容”方案，例如：`宽度缩减 12 mm（412→400 mm）→ 40HQ 装箱量由 520 箱增至 585 箱（+12.5%），按 $3,000/柜折算单箱省海运费 $0.64`。

  2. **内件装率反推（Unit → Master Carton）**：输入单个彩盒/产品尺寸 `l × w × h`、纸箱瓦楞壁厚（如双瓦楞 `14 mm`）、目标单箱限重（如亚马逊 FBA 限重 `22.5 kg` / `50 lb`）及每箱装率范围（如 `4–24 pcs/ctn`），自动遍历所有整数排列 `(nx, ny, nz)`，输出单柜总件数最高的 Top 3 外箱规格推荐。

### M4｜多客户 / 多目的港 LIFO 卸货分区与运费分摊（Multi-Stop & Consolidation）

**业务价值**：覆盖多客户拼柜（Buyer Consolidation）与多站点卡车派送（Multi-Stop），彻底解决卸货翻箱与运费分摊扯皮。

* **数据结构扩展**：

```
export interface ConsigneeStop {
  stopId: string;
  orderIndex: number;        // 1 = 第一卸货点（最靠近柜门，最后装入 LIFO）
  label: string;             // 客户名 / 目的港 / 卸货站点
  colorHex: string;          // 视觉分区颜色
  strictVerticalCut: boolean;// true = 严禁跨站上下叠放（严格按长度轴切片隔离）
}

```

* **算法与可视化要求**：

  * 严格按 `orderIndex` 倒序装柜（最远站点装最里面，第一卸货点装最靠近柜门）。

  * 当 `strictVerticalCut === true` 时，系统自动在两站点交界处生成虚拟隔断平面（可选插入 `20–50 mm` 隔板厚度），在 3D/2D 视图中渲染半透明分区隔断膜与站点标签。

  * **运费自动分摊表**：用户输入整柜海运费+拖车报关杂费总额后，支持按 **体积占比（CBM%）**、**计费重占比（W/M 取大）** 或 **占地长度占比（LDM%）** 自动生成各客户应付费用明细，支持一键导出 Excel。

### M5｜真实装柜物理约束与安全合规引擎（Physical & Compliance Engine）

补齐真实海运与公路运输中的 7 项高发“翻车”物理约束：

1. **门洞净空 + 尾门装卸余量**：所有封闭柜默认预留可配置的 `rearDoorClearanceMm`（默认 `100 mm`，用于绑带、拉网及防止货箱顶住柜门导致关门困难）。

2. **冷藏柜红线限高（Red Load Line）与回风间隙**：选择 `20RF / 40RH / 45RH` 时，自动激活顶部回风预留净空（默认扣减 `120–150 mm`，显示红色虚线警戒面），并禁止货物遮挡冷机出风口（前端预留 `100 mm`）。

3. **目的地公路限重预设（Road Weight Presets）**：在第 1 步载重上限旁提供一键预设下拉：

   * `海运船司标准限重`（如 40HQ \~26,500–28,600 kg）

   * `美国内陆 IPI / 公路标准（US Federal 80,000 lb）`（20GP 建议 ≤ 17,500 kg，40HQ 建议 ≤ 19,900 kg）

   * `欧盟公路 40T 组合标准`（建议净载 ≤ 22,000–24,000 kg）

   * `自定义限重`

4. **垂直嵌套叠加（Nesting / Telescoping）**：SKU 属性增加 `nestingDeltaHeightMm?: number`（例如堆叠塑料箱、椅子、花盆、套桶）。堆叠 `n` 层总高按 `H_total = H + (n - 1) × ΔH` 精确计算，而非 `n × H`。

5. **圆柱体六角蜂窝密排（Hexagonal Staggered Packing）**：当 SKU 形状为圆柱/圆桶/卷材时，算法提供“矩阵对齐排布”与“六角蜂窝错位密排（Staggered Hex）”对比，蜂窝密排可自动提升约 10%–14% 装柜率并标注错位间距。

6. **海运纸箱高湿 BCT 抗压安全系数**：承重校验中允许设置 `humiditySafetyFactor`（干燥内陆 `1.5` / 标准海运 `2.5` / 跨赤道高湿长航线 `3.0`），结合底层纸箱上压载荷，在承重热力图中高亮标红可能塌箱的危险层位。

7. **加固与防潮耗材 BOM 估算（Dunnage & Securing Estimator）**：根据第 7 步计算出的侧向/尾向空隙尺寸（`gapWidthMm`）与总货重，自动估算所需辅助材料清单：

   * **充气袋（Dunnage Airbags）**：当单处横向/纵向空隙在 `80–450 mm` 之间时，推荐对应规格充气袋数量；

   * **集装箱干燥剂（Desiccant Poles）**：按 20GP（推荐 6–8 条）/ 40HQ（推荐 12–16 条）及航程湿度系数给出建议量；

   * **缠绕膜 / 打包带 / 紧固拉带**：按打托数量与总重估算参考用量，纳入出货前准备清单。

### M6｜智能剪贴板粘贴与模糊 Excel/CSV 导入器（Smart Importer）

**业务价值**：彻底消除外贸跟单逐行手敲 30–100 个 SKU 的痛点，3 秒把客户的任何 Excel 询盘单变成 3D 装柜方案。

* **交互入口**：第 3 步顶部新增主按钮 `粘贴 / 导入 Excel`，支持三种零门槛方式：

  1. 拖拽上传 `.xlsx` / `.xls` / `.csv` 文件；

  2. 直接在文本框中 `Ctrl+V` / `Cmd+V` 粘贴从 Excel、WPS、飞书表格、Google Sheets 复制的任意多行区域；

  3. 下载 CargoFit 标准模板（仅作为备选，不再强制用户改表头）。

* **智能字段识别规则引擎（纯前端确定性解析 + 可手动微调）**：

  * **多语言模糊表头匹配**：自动识别中英文常见别名，如 `SKU/货号/Item No./Model`、`L/长/Length`、`W/宽/Width`、`H/高/Height`、`Qty/箱数/CTNS/Cartons`、`G.W./毛重/Gross Weight`、`N.W./净重/Net Weight`。

  * **单列合并尺寸解析**：自动识别类似 `60*40*35`、`60x40x35cm`、`24" x 18" x 12"`、`600×400×350 mm` 的合并规格列并拆分为 `L / W / H`。

  * **单位自动探测与批量换算**：根据表头括号（如 `(cm)`、`(in)`、`(lbs)`）或数值量级启发式提示（如长宽高普遍在 `15–120` 区间时提示“检测到疑似厘米 cm，是否一键转为 mm？”），确认后一键批量归一化入库。

  * **异常行预览拦截**：导入预览表高亮标红空值、负数、非数字字符，支持在导入弹窗内直接一键剔除无效行或在线修正。

## 5. UI / UX 设计规范与全端响应式体系（Design System）

本规范专为“工业级精密工具 + 高信息密度外贸工作台”定制，AI 编码代理在开发与重构所有页面、弹窗及组件时必须严格遵循。

### 5.2 字体排版与数值对齐规范

* **字体栈**：

  * UI 正文与标题：`"Inter", "Noto Sans SC", -apple-system, BlinkMacSystemFont, "PingFang SC", sans-serif`

  * 尺寸/重量/坐标/箱号等数值：`"JetBrains Mono", "IBM Plex Mono", ui-monospace, monospace` + 强制开启 `font-variant-numeric: tabular-nums`（等宽数字对齐，避免列表小数点与位数上下错位）。

* **字号阶梯（禁止出现 `< 12px` 正文或按钮文字）**：

  * 页面步骤标题：`20px / 600`（移动端 `18px`）

  * 区块小标题：`15px–16px / 600`

  * 表单输入与表格内容：`14px / 400`

  * 表头与辅助单位：`12px / 500`（单行不折行，单位可拆至次行）

* **中英文双语扩展容错规则（i18n Buffer Rule）**：

  * 英文文案平均长度比中文长 **30%–45%**。所有按钮、标签页、表头、下拉框设计时必须以 **English 模式为最宽基线** 进行排版验收，禁止硬编码仅贴合中文宽度的 `width`。

### 5.3 顶部导航栏与 7 步进度条布局规则

* **单行高度锁定**：顶部导航栏固定高度 `56px`，桌面端（`≥ 1280px`）强制单行 `flex-wrap: nowrap`，绝不允许任何按钮掉至第二行。

* **动态优先级收纳**：

  * `≥ 1280px`：展示完整核心入口（Logo + 草稿状态胶囊 + 文件与备份 + 方案工具 + 单位切换 + 主题切换 + 中/英切换 + 帮助/更多）。

  * `1024px–1279px`：自动将 `使用教程`、`其他工具`、`帮助与联系` 折叠进 `更多 ▾` 下拉菜单，保证主操作不挤压。

  * `< 1024px`（平板竖屏 & 手机）：顶部仅保留 `Logo` + `保存状态圆点` + `语言/单位快捷图标` + `汉堡菜单按钮 ☰`。

* **7 步向导条（Stepper）**：

  * 桌面端等宽横向平铺；

  * 移动端（`< 768px`）改为 **“当前步数胶囊 `步骤 3/7 · 录入货物 ▾`”**（点击可展开完整步骤抽屉直达任意已完成步骤），彻底消除手机端 7 步横向挤压与截断。

### 5.5 3D / 2D 视图、WebGL 降级与 SVG 尺寸标尺规范

1. **WebGL 降级体验规范**：

   * 启动时自动检测 `WebGL2RenderingContext` / `WebGLRenderingContext` 及软件渲染性能；

   * 若浏览器禁用 WebGL（如企业低配机/虚拟桌面/无头环境），无缝切换至 **Canvas 2D / SVG 真实坐标交互视图**（支持三视图切换、点击选中箱体、步进播放、热力图着色），顶部仅展示轻量级单行信息提示条（可手动关闭），不阻断任何业务操作。

2. **SVG 尺寸标尺防碰撞铁律**：

   * 所有尺寸标注文字（`L 12032 mm`、`W 2350 mm`、`H 144 mm`）必须带纯色背景遮罩（`<rect fill="var(--bg-surface)" rx="2"/>`）或严格偏移至尺寸线外侧 **`≥ 8px`**；

   * 严禁标注文字与蓝色尺寸线、柜体轮廓线或相邻标尺文字发生像素重叠；视口缩放时标注字号保持在 `11px–13px` 可读下限。
