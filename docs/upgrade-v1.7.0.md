# CargoFit v1.7.0 升级记录

发布日期：2026-11-28

## 核心升级项

### 1. D23（P2）：现场实装偏差回流与经验余量校准闭环
- 新增 `lib/packing/field-calibration.ts` 并集成至步骤 7 工程分析面板：
  - 支持直接导入 `/crew` 导出的 `CargoFit_ScanAudit_*.csv` 或手工登记现场实装箱数、地磅实称毛重（kg）与实测柜尾余隙（mm）。
  - 自动统计累积样本的平均装量达成率、地磅毛重偏差与尾隙偏差，给出下一柜安全间隙补偿建议（mm）与现场实用利用率上限参考（%）。
  - 支持离线持久化至本机 `localStorage` 及一键导出校准样本 JSON。

### 2. D18（P2）：本地工程快照库与跨版本指标 Diff 管理
- 支持在步骤 7 一键保存当前方案工程快照（含箱数、体积利用率、货重、托盘数、左右重心偏移与建议充气袋数），离线保存在本机浏览器中。
- 自动计算并展示历史快照与当前方案的实时 `Δ箱数` 与 `Δ体积利用率`，支持一键导出全部快照 JSON。

### 3. 质量与回归保障
- 新增 `lib/packing/v17-features.test.ts`（3 项单元测试），保持全部既有测试零回归。
