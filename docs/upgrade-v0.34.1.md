# v0.34.1 柜内区域无效草稿修复

日期：2026 年 10 月 16 日。基线 GitHub 8936bb5898c3a58269a6784a4e007fec496c9a4a。继承 [v0.34.0 障碍与禁占区](upgrade-v0.34.0.md)的全部功能与边界。

## 修复问题

实际浏览器中把区域移出柜内或清空名称时，倒推容量的严格几何解析在渲染中抛出异常，底层托盘预览的错误分支也再次调用同一严格解析。页面可能停留在旧视图，刚输入的草稿无法正常保存。静态设置组件测试没有覆盖它与容量预览共存的状态。

现在算术倒推在区域无效时返回零可用容量和零推荐量；底层托盘预览保留错误状态并显示零可用空间，不再从错误处理分支重复抛错。设置表仍保留原始草稿，提示用户修正或删除。正式求解、备份导入、编辑采用和现场交付继续使用严格校验，没有忽略无效区域来计算。

增加无托盘／启用底层托盘、单品／混柜、越界／空名称的组合回归；同时补齐区域求解提示和边界错误的英文映射。用户填写的区域名称仍原样保留。修正三视图无障碍读屏标签把禁占区误计为托盘的问题；区域继续显示，但托盘数量只统计实际包装。
