# v0.51.2 现场缓存写入失败后的恢复

状态：DONE（本页记录恢复补丁的软件、完整回归及双站实际面板验收）。日期：2026-10-21。基线 main `78d294b437e8f39cf15b90e4db30ba39e1201e60`。

## 修复的问题

现场记录因存储额度或权限未能写入后，本页仍暂存记录用于保护已装箱位。此前切走再打开现场面板，会重新从空缓存创建记录，再覆盖本页已知状态；访问第三个版本时也可能直接释放仍未保存的旧记录。这会削弱已装位置保护。

现在面板重新挂载时优先读取本页相同计划与版本的完整记录并校验箱位，明确提示“本页暂存不代替保存文件”。旧记录只有与新格式或兼容旧格式缓存逐字相同，才允许从本页暂存释放；缓存缺失、陈旧、损坏或无法读取时保留唯一已知副本。仍然使用相同的完整 JSON 文本备份及导入校验，不写成云端持久化。
