# v0.88.0 全单减托与工作台布局

在「装载配置」生成整体打托预览，打开「全单自动减托」，点「预览减托建议」。先核对托数、箱数和包装自重，再展开受影响托盘查看前后明细。写入草稿后可一次撤销全批。用「应用托内布置」确认，现场易执行与高密度参考两套方案会使用该布置。

装柜后从结果工具栏进入「已入柜减托」，搜索当前柜内的整托。各候选复用托内试排和整柜坐标校验，包括箱号、完整套装、锁定箱位、上下托承托及载重。已锁定整托与实测包络跳过。每轮最多释放 6 托，每个候选组最多 6 托及 240 箱。搜索预算、尺寸、实物保护和可用库存都会限制结果。

## 页面走查

| 页面或入口 | 核查点与本轮调整 |
| --- | --- |
| 货物清单、产品与订单 | 导入方式贴近导入按钮。表格模板及订单 CSV 收进「表格文件」。宽表保留自身横向滚动，键盘可聚焦表格区域及箱规输入。 |
| 装载配置 | 包装名称、可用量和比选方式集中。适用 SKU、散箱预留和整托堆叠按需并列展开。散箱按 SKU 紧邻箱数。 |
| 附件与固定预留 | 新增入口和质量摘要在前。名称、数量、计划重量、安装阶段及坐标分组。支承勾选与静载输入成组，资料和安装依赖可折叠。 |
| 装箱方案与三维查看 | 减托入口在结果操作区。采用手动方案后，即使另一算法尚无坐标快照，已采用的方案仍可查看和导出。 |
| 整托清单、坐标与导出 | 复核折叠、搜索、分页与全量导出入口。 |
| 顶部菜单、教程与弹窗 | 窄屏导航显示短标签，菜单随容器宽度展开，支持点击外部或按 Esc 收起。教程可搜索「全单自动减托」「附件 静载上限」等中英文关键词。 |

## 回归案例

- 5 托共 15 箱，另有整托锁定。减托候选保留 15 箱及 5 个完整套装，释放 2 托并减少 50 kg 包装自重，锁定托盘的货物坐标一致，两套算法采用后各装 15 箱。
- 已入柜的两层整托合并后释放上层 1 托，保留 3 箱与下方托盘位置。锁定上层箱位时保留原方案。
- 按 SKU 限制的两种包装可分别接收尾托货物。箱位锁定、空组、过期候选和后续步骤失败由原有坐标检查及事务规则处理。

设备级验收保留真实手机触控、客户 WebGL 环境、工厂试装及额定资料。账号与支付的生产配置继续按 [未完成台账](field-upgrades/unfinished-roadmap.md) 跟进。
