# CargoFit v0.95.0 — Gemini 回归修复

本次依据用户提供的 `cargofit_v0_94_1.html` 和八张标注截图修复。报告中的条目是复现线索；不将报告声称的通过结果当成本次验收结果。

| 问题 | 修改 |
|---|---|
| 为第二种货物建议尺寸覆盖第一种包装 | 采用配方时绑定产品／完整套装；不同货物生成独立规格，已有同组规格则更新原规格。全部规格共同参与最终求解。散装数量继续先行扣除。 |
| 预览对象与最终结果含义不清 | 明确显示全部包装的汇总、当前查看托及未打托 SKU。切换查看对象不会丢弃其他规格。 |
| 货物表套装列被固定操作遮住 | 桌面紧凑列宽和设置按钮；操作列移出固定覆盖层。窄桌面仍可完整横向滚动；手机保持卡片。 |
| 标尺尺寸与线、刻度重叠 | 尺寸标题和刻度使用分开的文字轨；绘制线段避开文字矩形，SVG 与 WebGL 共用同一渲染几何，物理标尺坐标保持不变。 |
| 只打托首页半屏留白及分割线 | 装载方式全宽，移除隐藏柜型留下的分割线。 |
| 散箱步骤文案 | 导航及下一步区分底托选项、散箱布置。保留顺序向导。 |
| 只打托结果文案 | 结果页签称打托预览；无车辆任务时运输固定与装卸路径标为不适用。承重缺失仍未核验。 |
| 英文装饰文字残留 | 移除 PALLET BASE、LOADING RULES、CALCULATED PLAN 装饰标签。 |
| 底座与围护预设对齐 | 底座单独完整行，与围护选项按同一左边界分组。 |
| 复核第八项与省略说明粘连 | 省略信息独立换行并留间距。 |
| 可用内尺含义不清 | 三视图及容量明细说明两端／两侧及顶部间隙扣减。 |
| 柜型参数改回标准值不恢复 | 所有柜内、门洞、净载重、开放面及底座参数一致时恢复对应预设身份，同时保留障碍等业务资料。 |
| 超尺寸／超重仅求解后提示 | 录入阶段按允许朝向、门洞、可用净空及单箱重量显示非阻断预警。 |
| 英文复核摘要大小写 | 统一 Data / Geometry / Bearing / Access / Securing。 |
| 包装初选预览缺少控件 | 材质、颜色、不透明度、线框和尺寸；材质等使用已保存的包装配置，线框是查看状态。硬件和简化预览均支持。 |
| 载荷明细冗长拥挤 | 网格、交替行、固定表头、搜索及分页；高度和规则诊断改为可横滑表格。全部数据继续参与计算。 |
| 首个搬运图标空白 | 修正 SVG 非法属性名称与双人搬运图标的裁切范围，保持用户提供的原矢量图形。 |
| 条码没有可读编号 | Code 39 图层内加入条码下方文字，随预览及 SVG／PNG 导出。 |
