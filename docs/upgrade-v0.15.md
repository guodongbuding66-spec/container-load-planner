# 装柜智算 0.15.0

## 已增加

- 方案归档与产品版本库：同名追加版本，不覆盖旧版本。本机保存失败时保留原目录；支持逐版本导出备份和恢复。
- 工作区文件包含已完成方案的箱位与锁定状态。恢复时重新校验坐标、产品归属、重量和成套关系，并从可信箱规重建全部指标，忽略文件中的缓存指标。旧的纯输入备份继续支持。
- 自动／手动计算、15／35／60／120 秒计算时限，以及停止后保留已经完成的独立算法结果。
- 未装入说明：区分门洞、柜体尺寸、剩余重量等确定限制与搜索未找到位置；不会将启发式失败描述为绝对不可装入。
- 包装上方累计承重：留空为未指定，0 为不允许上方负载；传递所有上层重量，按接触面积分配。求解阶段与独立校验都执行承重限制。
- 手动箱位：俯视图水平拖动、X/Y/Z 偏移、水平旋转、同一套联动、锁定、撤销／重做。只有校验通过的调整能同步到主三维、指标和导出。
- 整单多柜：候选柜型和库存上限、每柜费用、柜数或费用优先、每柜可行方案、剩余订单、进度中止与完整 JSON 导出。采用当前柜型的修改后尺寸，也支持保存的自定义柜型。
- 仓库模式：大字逐箱确认、按方案保存现场进度，以及可离线打开和打印的 HTML 指导书。

## 适用边界

- 手动锁定针对当前手动方案；重新求解会生成新方案。尚不提供锁定部分箱位后自动优化其余箱位的约束求解。
- 多柜采用逐柜启发式比较，不宣称全局最少柜数或最低总费用。费用优先要求所有候选柜型都有正数报价，费用币种应一致。
- 静态承重模型不代替包装试验和运输动态载荷评估；承重限制应来自实际包装数据。
- 方案和现场进度仍在浏览器本机保存。跨设备／站点依靠导出的备份；尚无账号同步或多人在线协作。
- 停止计算保留已完成的独立方案或完整柜；未完成的内部搜索不是已校验的交付结果。

## 验证

自动化覆盖：全层载荷传递与桥接分担、零承重约束、单品 1:2 套装箱数上限、无效箱位和锁定移动拒绝、重心更新、整单数量守恒、套装残余、库存限制、费用比较、版本归档与损坏数据拒绝、保存坐标重建及伪造重量／重叠拒绝。既有真实装柜记录回归仍保留。
