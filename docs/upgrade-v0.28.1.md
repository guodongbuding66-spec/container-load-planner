# v0.28.1 统一复核与真实外形交付图

实施日期：2026-10-15。基线：`2fc3e2c0b6cab37eef5313b8600e41a45b4ab056`。

## 完成本轮软件范围

- 增加 `reviewPlan` 适配层。数据、几何、承重、装卸路径和运输固定各自保存状态、范围、来源模型与问题对象；复用既有数据核对、方案校验、静态上压及路径检查，不改变求解器或判定规则。
- 顶部不再用几何校验通过推导“全部通过”。缺少承重、卸货站次或运输固定模型时保持未核验。只打托时车辆装卸路径不适用；缺少完整坐标时不宣称路径已通过。
- 直线后门、有限转向／抬升、开放装载面分别说明覆盖范围，搬运设备不纳入当前已通过范围。有限搜索失败标为未核验。摘要超过 240 装载单元时不运行无界路径计算，明确未完成复核。
- 主三视图、客户报告、PDF 和离线作业地图复用 `plan-projection`。使用原实体面投影，保留孔洞、凹槽及有符号朝向；包装部件沿用 `placedPackagingParts`，显示围护、箱盖和完整外高。
- 导出继续使用完整方案。离线进度只改变颜色与当前箱提示，不删减箱位。绘图部件重量为零，统计仍只使用原包装总自重一次。
- PDF 和离线导出补传原始产品输入，避免因导出端缺少承重资料而与页面结论不同。客户中英文报告使用同一五项复核结果。
