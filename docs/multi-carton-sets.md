# 多箱套装使用与验收说明

## 能处理哪些情况

套装不限制为“1 套 2 箱”。同一套装编码下可以有任意数量的箱规，并可为每个箱规定义每套需要几箱。

| 业务结构 | 建议录入方式 |
|---|---|
| 1 套 3 箱，三箱尺寸都不同 | 3 个 SKU 使用同一套装编码，每套箱数均填 1 |
| 1 套 4 箱，四箱尺寸都不同 | 4 个 SKU 使用同一套装编码，每套箱数均填 1 |
| 1 套 5 箱，五箱尺寸都不同 | 5 个 SKU 使用同一套装编码，每套箱数均填 1 |
| 1 台桌子 + 4 把椅子 | 桌子每套箱数填 1，椅子每套箱数填 4 |
| A、B、C 按 1:2:2 组成 5 箱 | A 填 1，B 填 2，C 填 2 |
| 超过 5 箱 | 创建套装后点击“增加箱型”，箱数不设 5 箱上限 |

## 页面操作

1. 切换到“多 SKU 拼柜”。
2. 在“多箱套装助手”中点击 2、3、4 或 5 箱套装。
3. 为自动生成的每个箱型填写真实 SKU、品名、长宽高、毛重和需求箱数。
4. 同一套装的套装编码必须一致；“每套箱数”填写该箱规在一套中的数量。
5. 套装卡片会实时显示箱规种数、每套总箱数、可组成套数及比例外零散箱。
6. 若需求比例不一致，可点击“向下对齐”。系统只减少比例外箱数，不会擅自增加订单数量。
7. 点击计算后，结果会同时给出完整套数、各组成箱数量和未装套数。

长、宽、高填写后，CBM 会自动计算到小数点后两位，下方保留四位精确值；无需再手工录入 CBM。

## 原子装载规则

- 求解器每次把一整套作为一个业务批次尝试装入。
- 任一组成箱因门洞、空间、方向、堆叠或载重原因失败时，本套已经临时放入的其他箱会全部回滚。
- 一套失败后不会继续产生同编码的后续半套。
- 独立校验器会再次核对各组成 SKU 的已装数量是否能除尽并得到相同套数。
- 体积与载重倒推会先显示完整套数，并附总箱数和各箱规明细；建议数量对齐到完整套装比例后再执行真实几何装载验证。

## 现场易执行策略

- 先计算完整套数，再比较 SKU 连续分区、可重复整层和规则余数层，不让工人逐套交替寻找碎片空间。
- 同一 SKU 默认固定一种方向；只有连续侧条补位时允许第二种同高度的水平 90° 方向，不允许侧翻塞缝。
- 非地面箱体至少 99.5% 底面受托。
- 几何方案完成后按支撑依赖重新排序：所有承托箱先装，再从柜头向柜门推进。
- 结果区显示单 SKU 最大方向数、全方案方向组合和局部支撑箱体数；这三项用于衡量现场复杂度。
- “极限利用率”保留为对比方案，不应在未经主管复核时直接替代现场策略。

## 现场追踪与导出

每个已装箱都包含：

- 套装编码
- 第几套
- 套内第几箱
- SKU、坐标、方向、层级和重量

这些字段会进入码垛进度提示、方案 JSON 和坐标 CSV，便于现场按套理货并发现漏箱。

## CSV 示例

关键列为 `setCode` 和 `unitsPerSet`。例如 1:2:2 的五箱套装：

```csv
sku,name,length,width,height,weight,quantity,setCode,unitsPerSet
KIT-A,A箱,1000,500,200,20,100,KIT-122,1
KIT-B,B箱,800,400,180,12,200,KIT-122,2
KIT-C,C箱,600,350,160,8,200,KIT-122,2
```

上例可组成 100 个完整套，每套共 5 箱。

## 验收覆盖

自动化测试覆盖：

- 3 箱、4 箱、5 箱不同 SKU 套装的整套回滚
- 1:2:2 比例的五箱套装
- 套号与套内序号连续写入
- 比例不一致诊断与安全向下对齐
- 目标利用率倒推后的套装比例一致性
- 用户提供的 1 套 2 箱记录按 110 / 230 / 275 套回归，并验证套号、总箱数和 46 kg/套毛重
- 两个单箱实装记录按 175 / 360 / 425 套和 235 / 505 / 600 套回归
- SLM-A64M 的 396 套异常报价与物理三维结果严格分轨
- 现场模式最多两种同高度平面方向、99.5% 完整支撑和支撑依赖顺序
