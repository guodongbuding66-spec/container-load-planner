# 017B 基准历史与版本比较

版本：v0.56.0。所属 U23，整体仍为 PARTIAL。入口“项目与资料 → 固定业务基准与算法质量”。

## 本轮契约

- 新运行报告记录每个案例的完整请求、策略、物理参考值及依据，保持 `business-2026-10-v1` 原始夹具不变。设备备注为用户选填，不采集设备身份；单次耗时不构成性能证明。
- 本次报告可原生下载、手动保存到本机历史；最多 8 份，超过后移出最早保存的报告。完整和停止后的部分报告分别保留；可导入单份报告或整份历史备份，再下载历史迁移到另一个设备或域名。
- 逐案例／策略对齐，比较箱数、套数、计划载重、报告中的校验标记和原始耗时。输入一致的范围按完整 JSON 记录核对，忽略对象属性次序，保留数组次序；必须同时符合当前声明的固定案例定义。它是数据一致性检查，不是身份认证或签名。
- 同版本且输入记录完整一致才计算增减和新增失败标记。旧版 v0.54／v0.55 报告兼容导入，但缺少输入记录时只展示历史／当前原值；不自动宣称算法改善或退化。案例版本、输入或参考依据不同，以及缺少某一运行，均明确显示比较范围，不把缺项当成零。
- 输入校验涵盖大小上限、数量／数值、唯一案例和策略、完整状态、物理参考差距、错误标记、候选来源数值一致性及输入结构预算。报告没有箱位坐标，导入的“通过”只是报告值，不重新证明几何、承重或每个 SKU 的装载改善。

## 本机历史与失败处理

每份规范化报告内容最大 2 MB，导入文件／历史最大 8 MB，每份最多 96 组运行，历史最多 8 份；当前业务版本只有已定义的 6×2 组。相同引擎版本和时间标识、内容不同的文件拒绝合并，全部导入验证后才更新页面。

刷新后读取本机历史；保存前再次读取有效历史并合并，减少旧页面覆盖新记录。此机制不是跨标签原子事务，也没有云端协作锁。存储拒绝或额度不足时保留本页报告并提示下载，既有存储不主动清除；损坏历史阻止覆盖，并允许下载原始内容。页面未完成的文件读取在离开面板后不再采用。

本机历史不包含在装柜工作区备份中；它有独立 JSON 备份。两个网站使用不同浏览器存储，跨站需显式导入。重要记录应下载保存。
