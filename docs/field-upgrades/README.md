## 已考虑并排除的重复任务

- 不重新从零实现三栏工作台、两点与间距测量、剖切、多选移动和偏好存储：已有实现，转为验收和扩展。
- 不重新从零实现多规格包装和库存限制：v0.28.0 已实现顺序启发式，v0.33.0 已增加候选比较与尾数优选，费用优化仍待后续。
- 不把圆台 L U T 型或 GLB 导入列为未实现：已有实体与导入路径，后续明确代理质量和现场包装条件。
- 不把搜索失败当作几何无解，不把静态承托通过当作完整运输安全证明。
- 不以模板图片或木纹材质自动赋予木箱承重能力。

## 共用验证约定

环境使用 Node 22.13.0 或以上，依赖按仓库锁文件安装。目标命令来源于当前 package.json：npm run test:unit、npm run verify、npm run build:pages。文档审查阶段仅核对既有 CI；v0.28.1 实施阶段已执行完整验证，见 [验收记录](../upgrade-v0.28.1.md)。

新增测试仿照 lib/packing/operations.test.ts 的 Vitest fixture 形式；UI 用现有 components/*.test.tsx 结构。没有硬件 WebGL 时，把 GPU 验收标为待完成，不能用降级视图的截图替代。
