# 计划 011B 长条箱承托与悬跨资料

状态：PARTIAL。v0.40.0 完成原始资料与独立几何预检，主求解约束和箱位采用拦截已于 v0.41.0 首阶段接入，实物垫木与复杂接触继续见 011C。基线 v0.39.0。继续货物和包装规划，不涉及叉车装卸动作。

## 目标

优先适配工具房、车棚的长条箱和多箱套装：保存货物允许支承区、最大悬跨／端部悬挑、垫木或底座接触位置、资料来源与版本。区分实际接触面、几何支承比例和有资料的跨距上限，缺少上限时保持未核验，不按外观或材质推断强度。

先建立原始数据和独立校验，再接托内移动、层型应用、整托排布及同源交付。箱体旋转后许可区使用同一坐标变换；模板不能复用旧的承托通过状态。保留其他锁定整托、订单余量和完整套装。垫木、底座重量及尺寸只计一次。

## 验收

长箱两端支承／中部悬空、端部超限、支承区错位、横转与翻转、实测资料变更、跨托冲突、混合高度、多箱套装完整性、工作区恢复、中英文及报告。取得实际额定前，仅完成数据和几何检查，不启用无依据的强度放行。

## v0.40.0 本阶段结果

支持原始 H− 底面、L／W 支承带、横向接触比例、中间悬跨、首尾悬挑、箱规绑定和来源版本；采用包装面板真实部件及精确矩形接触并集。侧翻、异型接触或缺资料保持未核验。托内编辑草稿与主方案复核及导出同源，不自动修改布局，也不放宽原有承托规则。详见[本轮记录](../upgrade-v0.40.0.md)。

剩余的候选约束、箱位采用拦截、垫木／支架实物接触、自定义支承面、异型接触和局部重排见 [011C](011c-support-enforcement.md)。取得强度额定前不作结构放行。
