# 计划 011B 长条箱承托与悬跨资料

状态：TODO。基线 v0.39.0。继续货物和包装规划，不涉及叉车装卸动作。

## 目标

优先适配工具房、车棚的长条箱和多箱套装：保存货物允许支承区、最大悬跨／端部悬挑、垫木或底座接触位置、资料来源与版本。区分实际接触面、几何支承比例和有资料的跨距上限，缺少上限时保持未核验，不按外观或材质推断强度。

先建立原始数据和独立校验，再接托内移动、层型应用、整托排布及同源交付。箱体旋转后许可区使用同一坐标变换；模板不能复用旧的承托通过状态。保留其他锁定整托、订单余量和完整套装。垫木、底座重量及尺寸只计一次。

## 验收

长箱两端支承／中部悬空、端部超限、支承区错位、横转与翻转、实测资料变更、跨托冲突、混合高度、多箱套装完整性、工作区恢复、中英文及报告。取得实际额定前，仅完成数据和几何检查，不启用无依据的强度放行。
