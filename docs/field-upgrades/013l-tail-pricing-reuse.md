# 013L 尾数费用报价保存与复用

2026-11-03，接续 013K。范围对应 U20 的当前单柜报价复用。

独立报价 JSON 保存运费、币种、包装单价、附加项目及有来源日期的手工汇率，保留未报价与明确免费。支持读取该格式 v1 及既有尾数费用报告 v1；CSV 和工作区文件不作为报价导入。

文件最多 5 MB。柜型及附件定义、包装物理配置、稳定订单行／SKU／套装身份和送货资料必须匹配，JSON 对象键顺序与订单行／包装列表顺序不影响匹配。货量与包装可用数量可以变化；采用后按当前已装箱、入柜包装与材料重新核算，不恢复文件中的旧数量、坐标、费用合计或复核结果。

导入先预览文件生成时间、币种、运费、各包装单价、附加项目计费单位／对象／来源及汇率来源日期。用户明确采用才替换本面板报价；文件声明不代表报价目前仍有效。读取失败、超限、未知格式、报价非法或适用资料变化时保留当前报价。

预览随当前报价、非法数字状态、输入配置或禁用状态变化而失效，往返修改不恢复旧预览；旧异步读取、被后续文件覆盖的读取和卸载后的采用不会执行。采用报价会重置当前数字草稿，包括相同币种、相同金额下的非法文本。独立报价可用于保留不完整资料，空白不推定为免费。

报价文件独立于工作区。当前未加入报价自动缓存、云同步、会员权限或支付；经济尾数搜索、拆托重打和跨柜优化继续待做。软件检查、发布和原生复用验收见 [v0.71.0](../upgrade-v0.71.0.md)。
