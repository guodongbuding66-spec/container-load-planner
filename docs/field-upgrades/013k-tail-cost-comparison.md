# 013K 尾数候选费用对照

状态：本阶段软件和双站原生验收完成；运行环境中断，原件归档 PENDING。经济尾数搜索等扩展继续 PARTIAL。

## 本阶段行为

- 完整尾数批次存在可采用候选后，展开“原方案与尾数候选费用对照”。两边各按一柜，使用相同本位币、运费和报价。
- 复用多柜费用规则：实际入柜包装计数；未使用的库存不收费；每订单费用每边各计一次；材料按柜内附件数量；外币使用明确来源和日期的手工汇率。
- 显示已装箱数、实际散箱、包装用量、计划毛重、已知小计、已配置项目完整合计、已装每箱配置费用和候选减原方案的差额。
- 运费 0 沿用现有“未报价”语义；包装勾选报价后可明确填 0。缺包装／附加报价或汇率时，总计、差额和每箱费用保持未知，已知小计单独保留。
- 报价只用于当前对照，不修改订单、求解候选或自动采用；重新运行试算后重新填写。切换本位币清空运费、包装单价与换汇资料。
- 独立 JSON 内含报价、数量、成本、原完整尾数报告和五项复核；CSV 含逐项数量、单价、汇率、小计和差额，中文／英文、BOM、CRLF 与公式防护。空值表示未核算。
- 导出前重新校验原方案、选中候选及完整批次，按复核箱位重建重量和数量。输入、范围、方案或采用权限变化后，旧导出方法不能输出当前报告。

## 边界

核算范围为“已配置项目的当前单柜费用”。原方案与候选的交货数量不同，费用高低不能单独证明方案优劣；没有把剩余订单后续运输、未配置人工、税费或运输固定强度补成已知。五项复核中的未核验状态原样保留。

本阶段不按费用搜索或重排所有候选，不实施自动拆托／重打、跨柜经济优化，也不增加在线支付。报价不加入工作区备份，费用报告用于留存，不能作为工作区恢复文件。

## 验证

覆盖实际箱数与包装计数、已使用／未使用包装、缺运费／报价／汇率、明确免费、外币来源日期、一次性费用、非法金额、过期规格、独立几何复核、缓存重量篡改、完整批次、捕获旧方法失效、CSV 空值／公式／引号及中英文显示。发布、实际浏览器下载和剩余限制见 [v0.70.0](../upgrade-v0.70.0.md)。
