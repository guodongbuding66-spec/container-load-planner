# 015D 独立测量复核 PDF

日期：2026-10-23。版本：v0.59.0。U18 继续 PARTIAL。

## 功能契约

已保存测量增加“下载测量 PDF”。报告包含点击导出时的全部已保存记录，包括隐藏和历史记录；三维显隐、播放、隔离及剖切等查看筛选不筛除报告条目。不包含未保存的临时测量。

点击时同步冻结记录、有效状态、当前方案范围、语言、单位和小数精度；后续修改输入、名称、显隐或语言不改变正在生成的报告。页面显示生成中，重复点击不会重复导出；失败可重试，不修改测量或装柜数据。面板卸载后不触发迟到的下载。文件下载是否最终完成由浏览器确认。

## 内容与状态

概览包含生成时间（UTC）、查看柜型、策略、引擎、当前变化检测码、布局模型校验状态、当前／需重测数量、单位精度、完整范围说明和记录索引。变化检测码不具备身份认证或数字签名能力。

每条记录单独开始页面；长内容自动续页，重复记录名称与状态。包含测量名称、当前有效／需重新测量、直线距离、A/B 世界 XYZ、轴向分量、原始毫米端点和距离、记录时间与编号、记录空间、来源箱托编号和包络。剖切外包络保留取点范围；规则实体保留外形参数、朝向及轴符号；捕捉与柜壁依据单列。

“当前有效”仅表示与导出时完整方案匹配，不表示工程核验或实装验收通过。历史值不重新套用当前箱位；明确标识“历史快照，不用于当前箱位”，保留原始坐标和数值。

每条记录附 X/Y、X/Z、Y/Z 三个等比例快照线框投影，仅绘制该记录的来源对象与端点。规则实体使用保存的真实边界，外包络使用保存的取点范围；不把当前全柜图、路径或承托结论混入历史图。线框投影不是可交互 GPU 画面，不改变装箱校验。

## 数据和兼容

导出先按测量 v1／v2 兼容规则重新检查全部记录，拒绝坏端点、非法参数、重复编号或超限记录。沿用最多 20 条、256,000 字节的独立存档限制。显示使用所选单位和精度，原始毫米值另外打印，避免舍入值被当成原始输入。

测量 PDF 为独立图像页面，沿用现有指导书的中文 Canvas／JPEG PDF 方式；不承诺可选文本、搜索、矢量或无障碍标签。PDF 不能恢复、合并或编辑记录，跨站迁移继续使用测量 JSON。工作区、装柜清单及原有装柜指导书不自动包含这些记录；原有指导书字节组装器仅抽为共享模块，行为不变。

## 验收范围

软件检查覆盖点击快照、当前／历史与隐藏记录、单位和原始毫米、剖切及实体快照、20 条及长 Unicode 内容分页、历史投影、退化投影、Canvas／编码失败、重复点击、卸载取消及中英文入口。生产构建、双站原生 PDF、实际分页和图片检查结果见 [v0.59.0](../upgrade-v0.59.0.md)。
