# 013B：跨柜共享包装库存与运费、包装费比较

状态：IMPLEMENTING，基线 v0.46.0。具体叉车操作仍 EXCLUDED。

- 多柜工具接入直接装柜及先打托后装柜；独立只打托不参与多柜分配。
- 包装各规格可用数及生成总上限在整张订单内共用；指定散装数量也只分配一次。选择一柜完整方案后才扣减实际入柜包装与货物；试算候选之间不互相扣库存。
- 未入柜的预生成单元只是候选，不当成已制造实物；下一柜可对剩余订单重新打托。不拆已入柜的整托，前缀方案在尾柜优化中保持不动。重打人工和损耗费用尚未建模。
- 每柜继续执行完整套装、门洞、几何、承托和重量校验；整单再独立核对订单、散装配额、包装库存、柜型库存和费用守恒。
- 以同一币种填写运费与每个包装规格单价。包装可明确免费（单价 0）；未报价保持未知，不按免费比较。费用优先必须具备可参与方案的完整报价。
- 完整方案先比较是否完成订单；余货方案比较必装及高优先级完整货量，再比较目标。仍是有限逐柜与尾柜启发式，不证明全局最少柜数或最低费用。
- 清单、汇总 CSV、全柜坐标 CSV 和带输入及报价的 JSON 备份同源；导入前重新校验，订单或打托输入不一致不能混用。坐标以柜号区分各柜内局部实物 ID。

本轮费用范围仅运费与包装，固定材料、人工、返工、税费及换汇未计。真实 GPU 与现场试装仍 PENDING。测试与双站实际验收在升级记录补齐。
