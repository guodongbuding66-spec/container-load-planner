# 阶段 012 木箱正式自动叠放

版本：v0.45.0；状态：四角单列首阶段软件已实现，测试和正式站验收见[交付记录](../upgrade-v0.45.0.md)。完整构建 1,165 项单元测试、21 项 HTML 检查和双站实际验收通过。U08 整体保持 PARTIAL。具体叉车操作继续 EXCLUDED。

## 契约与迁移

- 默认底置。额定资料新增可选 `automaticStacking`，旧文件缺省为未启用。启用、关闭或修改结构／额定资料后均须重新人工核对；核对键精确绑定当前结构和资料。显示颜色、透明度不改变额定资料。
- 首阶段仅四角承压脚、对应同位立柱、连续底板接触片及框架／条板围护与箱盖。真实部件生成许可区；不能用箱盖中部整面、货物平顶或外接长方体替代传力路径。
- 仅柜底起始的单列：每层一只完整木箱，唯一完整下箱；四只脚分别完整落入下箱唯一许可区，且高度贴合。每列最多 20 层。所有参与木箱均须启用、资料有效，朝向在允许范围内。
- 每只下箱检查全部上层毛重之和不超过顶载；每条路径分别用“本箱毛重＋全部上层毛重”作保守上界，不假设四角均分，也不把四条上界相加计重。每只箱的额定层数表示含自身的上方列长度，顶层可为 1。
- 木箱叠放层数和顶载使用该规格已核对的木箱额定资料；开放托盘继续使用原整托规则。木箱内货物的承托、上压与外部结构列分开，外部上压不穿过箱盖算到内部纸箱。
- 候选在进入结果前即检查接触和累计限制；不合格候选继续搜索其他可行位置。有限搜索不是最优或无解证明。完整单位仍受外包络、门洞单件通过、柜内边界、障碍、保护间隙及整柜重量约束。
- 主方案、托内编辑、整组调整、采用和备份恢复共享当前统一校验。上层增货可能令下层超限，整次修改拒绝并保留原方案。旧文件的通过状态不能代替当前校验，单规格来源的结构及额定资料均核对当前输入。
- 播放和导出按完整单位排序，下箱完整内容先于上箱；不同内壁厚度不能让上箱货物先出现。独立“只打托”编组区继续平铺，不把展示坐标当作装柜叠放。
- 主清单、实际静载表、热力图、CSV、HTML、PDF 和备份区分额定资料与实际叠放结论；静载通过不代表材料、连接件、局部地板压力、绑扎或运输动态通过。

## 未完成范围

多箱联合承托、跨梁、箱盖中部板件、混合木箱／开放托盘的垂直列、偏置复杂接触、托内支承件与叠箱同时使用、弹性与结构强度仍未实现。缺少实际结构来源和额定资料时保持未核验并底置。真实 GPU、多浏览器硬件与现场试装仍 PENDING；没有增加具体叉车装卸模拟。
