# 014B1：交付版本与箱托登记编号

状态：IMPLEMENTING，v0.49.0；基线 v0.48.0。014B 整体仍为 PARTIAL，具体叉车操作 EXCLUDED。

## 本轮契约

- 单柜或独立打托方案经完整箱位与现有数据审计后，由用户明确“登记并下载版本备份”。计算候选不自动登记；登记不证明已经制作、装柜或运输安全。
- 交付 planId、revisionId、每箱及每托／包装 unitId 使用独立随机 UUID。数字 revision 只表示本地递增次序；previousRevisionId 链接上一版本，同号分支由 revisionId 区分，不自动合并。
- 局部移动、旋转、转托及重排保留可确认的单元编号；以原局部 ID、源行、批次和物理规格指纹确认。编号不依赖坐标或数组次序。业务资料和箱位变化标为待登记，采用编辑不会冒充已发布下一版。
- 新增单元在登记下一版时分配新编号；移出方案或批次／物理规格变化的旧编号记为 withdrawn，并保留撤出版本。撤出仅指不属于当前交付方案，不宣称实物已销毁或退库。再次加入不自动复活旧号。
- 整单重算生成未登记候选，不根据可重复的求解器局部编号猜测实物继承。明确复制为新计划时，新计划号、版本号及全部单元号独立，保留 forkedFrom 来源；归档库复制已登记方案采用相同契约，恢复旧版则保留旧号。
- 登记即时下载含源输入、箱位及身份的工作区 JSON；普通本机输入草稿不保存箱位或交付版本。完整历史由每次版本备份保留，恢复按当前规则重新校验。旧文件没有登记信息时继续作为未登记候选读取。
- CSV 在旧列后追加计划号、数字版本、current／draft 状态、单元号和版本 UUID；未登记新箱号留空。客户／离线报告及 PDF 展示版本与编号，草稿明确提示尚未登记下一版。现场进度指纹纳入版本身份，复制计划不沿用旧现场进度。
- schema 1 校验格式、唯一性、上限、父版本、撤出记录和当前绑定；完整箱位上限 20,000 箱，登记单元至多 20,200，撤出记录至多 50,000。摘要只是变更检测校验值，不是数字签名、身份认证或防恶意篡改机制。

## 未完成边界

源订单尚无跨全部方案的已制作实物库存台账；包装规格采用本方案结构指纹，没有建立跨订单统一的规格身份库。多柜／尾柜重建的贯通身份、拆托替代关系、实物制作确认、旧版本扫码状态、防重扫码、缺损事件、已装区域锁定、离线去重和多人分支合并仍待实现。不能用当前登记号宣称这些已经完成。
