# 016A 计划重量与完整装载实称

版本：v0.52.0。U21 软件首阶段，实际地磅、VGM 签发和自动设备采集不包含在本阶段。

计划货物毛重来自已装 SKU 明细，含用户已计入该毛重的纸箱、部件及支架；实际另计的托盘／木箱来自当前箱位包装自重，固定与防潮材料来自整柜附件，分别显示并只计一次。三项之和必须与方案装载总重一致。柜体皮重不在装载净载荷中，不从柜型尺寸或通用预设猜测。

实称记录绑定当前已发布的 planId、revision、revisionId 和箱位校验摘要。只接收本版本完整装载的人工读数：总重减柜体皮重，或者直接实称净载荷。总重法必须填皮重及其来源；直接净载荷法不接受二次扣皮重。称重时间、设备／来源和磅单编号必填；用户明确确认覆盖本版本全部货物、包装及材料，且不含车辆／人员。

每次复称追加独立记录，不覆盖以前记录。计算与计划差额、百分比和超过方案净载重上限的差额；超限读数必须保留并显示，不能拒收后制造正常状态。无读数仍未核重；零计划载荷不计算伪百分比。记录不会修改货物数量、现场已装标记、布局或结构校验，也不能证明货物未少装。

独立 JSON 备份保留全部记录，不混入工作区或现场事件文件；提供 JSON 文本备用、CSV、同版本导入合并、防重复和同编号冲突拦截。上限 100 条／1 MB，不静默裁剪。缓存损坏阻止写入并提供原始数据下载；本页内存优先恢复未落盘记录，存储写失败明确提示立即备份。该内存和浏览器缓存不能代替外部保存文件。

旧版本或复制计划的实称不能自动迁移。修改箱位后应恢复原版本查看其核重资料，并按新版本重新确认称重范围。后续独立账号／云端归档见[账号与会员方案](../account-membership-plan.md)。真实称重设备接入、附件逐件实称、跨柜对账、皮重铭牌核对及称重凭证验真仍待接入实际数据和设备。
