# 计划 009 整柜附件及固定预留

基线 v0.35.0，GitHub 781a96828db230ff6f6e235864e8642e2eafece0。本阶段只实现手工确定的轴对齐包络、计划重量、材料清单和安装依赖记录。运输固定强度、绑扎角度、锚点能力、气袋接触压力、受力与现场施工仍未核验。

## 实施范围

- 整柜附件复用柜内区域的同一坐标和排除几何：实体材料占位与安装预留分开；每行包络覆盖该行全部数量，分散位置分条填写，不将数量再次乘到空间上。
- 垫木／挡木、气袋、绑带、挡杆／支架、防潮与其他材料保存数量、单件计划重量、资料来源、版本、关联产品和安装阶段。没有计划重量不能计算；明确的零重量允许保存。安装预留始终为零重量。
- 附件计划重量按数量乘单件重量，只计一次；不写入货物数量或托盘自重。已经包含在箱体或托盘重量中的附件不得重复录入。两套算法、独立校验、剩余载重、重心、分区重量、编辑恢复和补货共用此统计。
- 附件与普通区域的重叠体积只扣一次。所有包络始终禁止货物和补货占用，不提供承托；保留目前不支持铺底层托盘、只打托的明确限制。
- 记录装货前／装货后阶段、关联货物和前置附件；拒绝循环、缺失依赖和跨阶段矛盾。生成拓扑顺序与最早装箱步骤参考，部分未装货物明确显示，不声称安装可达或实际动作已验证。
- 工作区、方案、CSV、附件清单、客户与离线报告、PDF 保留相同资料与范围；改变附件使方案及现场进度失效。运输固定仍显示未核验。
