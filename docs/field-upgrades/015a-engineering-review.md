# 015A 整托实测与静态轴荷首阶段

版本：v0.54.0。状态：软件首阶段，验收见对应升级记录；U13、U17 继续保留 PARTIAL。

## 整托实测

入口在“交付与现场”。要求完整有效且已登记的当前交付修订。仅适用于已入柜的预打托／木箱单元，不把柜底铺托盘或只打托预览当作整柜结果。

按当前柜内 X／Y／Z 方向输入实测整托长宽高、向柜头及左侧的突出量、附件增重、重量是否已包含、测量来源与日期。高度包含底座。预填尺寸只代表标称值；来源、日期及附件重量须明确填写。

保守占位是原占位与实测外包络的并集，较小读数不能消除既有货物。重新检查有效柜边界、后门净宽／净高、其他整托、散箱、实体与预留区域，以及规格间隙。开放式装载空间不检查后门。结果列明冲突对象；未实测单元保留未核验。附件已计重不重复加重，未计重部分只进入独立试算；超出载重明确报错。

不自动采用箱位、不重排、不推算新装箱量、不改变原计划重量。静态轴荷使用原计划重量，不混入尚未采用的附件试算。承托、包装强度、真实表面干涉与装卸转向不由外包络通过推定。

## 静态轴荷

只支持给定的刚性两支点模型，不支持铰接牵引车／挂车、多轴组内再分配或动态工况。参数：支点间距、柜头相对前支点的有符号位置、实际空载前后支点反力、额定前后支点及整车总重、资料来源与日期。额定值未知可留空，不能默认为零或安全。

从实际箱重、包装重量、整柜附件重量分别计算力矩。显示重心中的零重量视觉替代值不参加受力计算；几何重心假设均匀密度，用户可用已知的完整载荷纵向重心替代。已知重心以实际柜头为原点，限制在柜长内。

设载重 W，支点间距 L，载荷重心距前支点 x：后支点附加载荷 W×x/L，前支点附加载荷 W−W×x/L，再分别加实测空载反力。检查总重、额定上限及总反力小于零的离地趋势；悬伸造成某项附加载荷为负并不自动判错。检查质量守恒。通过仅表示给定静态模型范围内未见超限，不构成道路合法性或现场运输认证。

## 记录与恢复

工程资料与工作区、核重和作业记录分开备份，绑定 planId、revisionId、signature。最多 200 个单元，2 MiB；未知计划、旧修订、重复单元、无效日期／来源、异常数值或不完整坐标拒绝导入。派生结果重新计算，不信任文件中的结论。

页面内 Map 保留同版本记录；浏览器保存失败保留本页副本并提示导出。损坏原始缓存阻止覆盖并允许下载原文。保存前检查缓存是否被其他页面改变；这不是跨页原子事务或云端同步。导入须审阅并明确替换，导入前可以导出当前资料。

## 后续缺口

整托实测自动采用并重新打托／装柜、分项附件形体、更精细接触与支承，以及铰接车辆或多支点模型仍未实现。额定结构资料、实际称重与试装需要真实数据，不能用示例参数代替。
