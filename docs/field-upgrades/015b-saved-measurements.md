# 015B 多条外包络测量与失效管理

版本 v0.57.0，所属 U18，整体继续 PARTIAL。入口：主三维工作台 → 属性与测量 → 已保存测量。

## 本轮契约

- 保存两点、两箱和柜壁距离，支持名称、显隐、删除及撤销最近一次删除。最多 20 条，不自动移除旧记录；保存成功后清空当前取点并解锁，便于继续测量。
- 每条保存原始 mm 坐标、箱号／托盘号、源包络和取点时包络、逐端点捕捉方式、柜内尺寸与间隙、方案变化标记及时间。长度、坐标与分轴距离从记录重算，显示单位和小数精度不修改源数据。
- 点、边、面是外包络特征。剖切后形成的人工边角另标“剖切外包络”，不冒充实体斜面、曲面或凹槽。取完点再改捕捉或剖切设置，不篡改已取点的来源。
- 复用既有方案变化标记，排除临时求解 ID；相同输入与完整方案恢复后可继续有效。移箱、换柜、改变策略、形体或其他受跟踪方案资料后，保留历史数值并标“方案已变化，需重新测量”，不继续画线。不自动平移旧点、不假定旧点仍是同一实体特征。撤销回到完全相同方案可恢复有效。
- 三维和无 WebGL 的真实坐标俯视图均显示有效记录；沿用尺寸开关、颜色、单位、精度及可见货物／剖切筛选。俯视图线段为平面投影，标签仍是三维距离。三维叠加使用既有几何和材质释放流程；软件渲染测试不替代真实 GPU。

## 独立保存与文件

本机键 `cargo-fit-measurements-v1`，格式 `cargo-fit-measurements` v1，原始文件上限 256,000 字节。使用独立 JSON 备份跨站迁移，不包含在装柜工作区备份、PDF 或货物清单中，也不作为装载校验或现场认证。

导入前完整检查模式、日期、有限坐标和尺寸、包络包含关系、捕捉点、壁面、唯一编号、最多 20 条及原始字节数。相同编号相同内容不重复加入；内容冲突或任一记录无效，整次导入不采用。

损坏本机数据阻止覆盖，允许下载原文；本页新记录仍可下载。额度或访问失败时保留本页记录并提示下载。写入前核对本机原文是否被其他页面改变，发现变化则拒绝本次写入并保留本页供备份；这不是跨标签原子锁。文件读取在离开页面后完成，不再采用。撤销删除仅保留本页最近一条，刷新前重要数据应下载。

## 验证与后续

核心测试覆盖同方案恢复、策略／几何变化、目标篡改、六个柜壁、混合捕捉和剖切取点、显隐／过滤、去重／冲突／上限及坏数据。界面测试覆盖中英文、失效标签、可访问名称和备份范围；实际挂载测试覆盖存储失败、损坏原文、旧页面冲突、撤销及离开后的读取。既有三维叠加回归增加保存后的尺寸开关联动和失效移除。

正式站验证与证据见 [v0.57.0](../upgrade-v0.57.0.md)。实体面／曲面／凹槽测量、编辑后自动追随实体特征、PDF 测量页、云端共享和真实 GPU 仍未完成。具体叉车操作 EXCLUDED；账号会员付费保持后续独立范围。
