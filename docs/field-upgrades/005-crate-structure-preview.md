# 计划 005 木箱实体传力路径与独立叠放结构预览

基线 v0.31.0 / GitHub 4cc2d46ee8016c86582cef9adc4e5809dd7ee3e2。承接计划 004 的停止条件，单独定义结构几何工作，不启用生产自动叠箱。

目标：底脚、底板接触片、立柱、箱盖角部来自与显示相同的包装部件；逐段核对完整覆盖、同轴与 Z 连续性。独立预检使用实体底脚和下箱实际箱盖角部，输出完整路径依据。新增可旋转结构预览、逐箱逐角选择、错位高亮及无 WebGL 时同源坐标投影。

范围：packaging.ts 部件角色标识；新增 crate-structure.ts 及测试；crate-bearing.ts 接入几何；资料编辑与独立预检面板；独立包装结构预览及对应测试、样式、升级说明。其余求解与整托校验仍保持底置，不修改通用碰撞、订单数量、质量、套装规则或生产额定预设。

验收：四条实际路径、短底座、90°朝向、不同尺寸、断柱/缺脚/重复部件/板件不覆盖/悬空箱盖等几何缺陷；导出保留路径来源；预览只展示包装、不把示意图标成结构强度通过；英文无中文；预检禁用或数字未完成时预览与导出同步暂停。已有完整回归与静态构建必须通过，两个网站同步。硬件 GPU 与实物资料仍待验收。

停止条件：不得用整块封板中部替代立柱，不按面积均摊四角载荷，不虚构连接件强度，不将独立预检采用为主方案。后续接入通用承托和自动叠放须另立计划并完成实际结构及额定资料复核。
