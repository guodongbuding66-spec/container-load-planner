# 计划 007 柜内障碍与禁占区

基线 v0.33.0，GitHub 60675b91789e06bfcea63ed06fc2a66af2a6bfac。范围来自[未完成项目与自动实施计划](unfinished-roadmap.md) U02。

首阶段实现最多 16 个轴对齐长方体区域，分固定障碍和禁占预留两类。输入坐标均为实际柜内柜头、左壁、地板起点的 mm；求解坐标扣除原有安全间隙，区域先与有效空间裁剪。允许区域互相重叠，按精确轴对齐并集扣除容积一次。

区域不进入货物订单、箱数、包装自重、承托索引或层数；真实材料重量留给附件模块。直接拼柜、单品容量及先打托后装柜接入同一约束；最后一项使用完整托盘／木箱外包络。开启区域时暂停不认识障碍的单品快速排布和历史经验标定，改用显式候选几何求解。只打托和自动铺底层托盘暂不支持，明确报错或阻止计算；柜外打托预览不应用车辆区域。

独立校验、编辑采用、工作区与双策略恢复重新检查区域。空隙分析排除区域；直线与有限转向／抬升路径保留固定障碍。开放装载没有完成绕行和吊装验证，路径保持未核验。

主三维、无 WebGL 俯视、三视图及客户／离线／PDF 图保留区域颜色；播放或隐藏货物不会删除区域，区域不计入货物占用长度提示。报告另列原始物理坐标与范围。CSV 用 site-exclusion 单独记录类型，physical-inner 坐标用途，重量为零，不能把它当成新增货物。

验收包括：重叠容积、间隙裁剪、区域上方无承托、双策略与单品容量、源输入未变、备份与自定义空间、篡改同体积位置、完整整托、固定障碍路径、空隙排除、交付投影和 CSV 行类型、中英文及无效数值阻止计算。最终执行 npm run build:pages，并核对双站实际版本。

后续子阶段：底层铺托盘避障、门框／门槛专门参数、门洞偏置、任意几何障碍与设备扫掠。首阶段没有实现叉车、材料重量、安装动作、固定强度或地板承载；GPU 与现场实测仍须单独验收。
