# 013O 同量经济尾数自动选择与独立复算

2026-11-03，v0.74.0。接续 013M／013N，推进 U09／U20。当前完整尾数批次至少两个可比候选、所有同量候选的实际用量与配置报价完整时，自动选择最低配置费用的配额，再单独求解和复核，预览后明确采用。

## 选择与采用边界

- 保持数量优先候选每个源订单行的已装数量，不能以相同总箱数替代相同订单行交付；仍保留原基线逐行不减量要求。
- 仅选择当前已完整评估的单组快速／逐量或两至四组联合网格；不增加组合、箱数、订单或包装库存。并列费用先保留数量候选，否则优先较少新增散箱预留，再按批次顺序确定。
- 运费、实际包装、附加材料／人工／返工和有来源日期的外币换算沿用现有核算。缺报价、缺用量、同量候选不足或过期批次不能启动自动选择；不把未知报价当免费。
- 单独复算最多 30 秒。完整订单、套装、几何、承托、载荷和箱位独立校验；实际逐行交付或包装用量与已评估候选不同即拒绝，不自动改报一个新金额。
- 预览不改变数量候选或原方案。点击“采用经济配额并重新计算”后沿用当前版本保护和打托／装柜流程；已交付版本仅预览，实测／锁定单元沿用原禁用规则。
- 报价、非法草稿、适用输入或试算批次变化即使随后改回，也使旧经济预览失效；重跑、停止、超时、错误、卸载和迟到回复均不能恢复旧采用或导出入口。

经济 JSON 格式为 `cargo-fit-tail-economic-preview`／版本 1，包含数量候选与经济候选配额、完整配置费用和节省、可比范围、独立复算标记、现有完整费用报告、原订单、全部候选、逐源行数量及五项复核。CSV 同时包含现有费用明细与经济选择、两金额、节省及配额；均标记未采用预览。

受控单行 14 箱案例：合法历史基线为 8 箱／一托，完整逐量 1–6 的数量优先候选为 14 箱／两托／一散箱；运费 100、每托 20，经济配额为 6，复算 14 箱／一托／六散箱，配置费用 140→120。受控两组联合各 14 箱案例：四托 180→两托 140，逐源行仍各 14；1:2 套装测试保持完整比例。这些不是原用户 596→16 工作区复现。
