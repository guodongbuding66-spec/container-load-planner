# 016B 防潮、唛头与人工过程核对

版本：v0.53.0。U22 首阶段软件，按当前有效交付修订记录人工核对；不做具体叉车装卸动作。

## 本阶段行为

装货核对包含柜况、清洁与干燥、整单箱数和套装、唛头与箱托编号、防潮依据、封柜及封号说明。附件清单直接引用当前方案的类型、数量、计划重量、来源、版次和安装依赖，不另外插入材料或重复计重。预留区域明确为零重量的区域核对，不显示成实体材料安装。

装货前附件在整单核对前确认；装货后附件在整单核对后确认。防潮核对还依赖所有已配置防潮附件。封柜核对依赖唛头、防潮以及装货后附件。未配置附件不会自动得到“不需要防潮”结论，必须由核对人说明依据。

到货核对独立于装货记录，收货方没有装货记录也能记录封号、外观和异常。拆除顺序反向引用已有安装依赖：装货后附件在卸货清单核对前，装货前附件在其后；最后材料清场和异常交接。此顺序是人工清单，不证明施工可达性或临时支承安全，现场必须确认拆除条件和支承安排。

## 版本、历史和冲突

每条事件必须填写核对人和实查说明；附带系统登记时间、任务、承接事件、前置确认编号。可以确认、登记异常或撤回重查。只有全部前置项当前已确认才允许确认本项。

同一任务保留所有事件。前置项被撤回、出现异常、冲突或重新确认后，下游旧确认标记“需复核”，并继续向后传播；即使前置重新通过，也不能自动恢复依赖旧编号的确认。并行分支不会按最后时间覆盖，必须查看完整历史，明确勾选复核合并后登记新事件。相同事件编号却内容不一致时整次导入拒绝，不替换当前记录。

记录绑定 planId、revision、revisionId 与当前方案变化摘要。复制计划或其他修订不能混入，也不自动迁移已确认状态。摘要仅检测方案变化，不是数字签名或身份认证；核对人是人工填写，账号尚未接入。

## 保存和限制

独立 JSON 备份、完整只读 JSON 文本、全历史 CSV；不包含在工作区备份或现场事件备份中，也不改变箱位、数量、重量、已装状态和结构校验。最多 500 条事件／2 MB，超过上限拒绝，不裁剪历史。

重新打开优先恢复本页内存；读存储被拒绝时仍可在本页登记并另存。缓存损坏阻止写入并提供原始记录下载。保存前合并已能读取到的本机记录；额度、读取、解析或写入失败时保留本页记录并要求外部备份，不覆盖损坏原文。浏览器存储没有跨标签页事务锁，极端同时写入仍须各自备份并显式合并；没有云端同步或账号级持久存储。

尚未实现：唛头所在实体面的自动遮挡／可读朝向判断、湿度与露点／材料吸湿量计算、禁贴靠面的专用规则、暂存区域随工序切换、临时支承结构与拆除安全模拟。不得由本阶段人工确认生成锈蚀概率、防潮保证或固定强度认证。
