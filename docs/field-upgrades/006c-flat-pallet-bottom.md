# 006C 平托盘底部结构

目标版本：v0.62.0。依据用户上传的《货物运输托盘的类型及选型方法》PDF 第 1–4 页示意，补齐无底板单面托盘与带底部纵板托盘的结构差异。仅参考分类和外形，不把文中参考价、材料描述或出口概述当作报价、额定资料或合规判断。

## 本阶段

- 墩式和纵梁底座可选择“底部纵板（原结构）”或“无底板（单面型）”。无底板时支承块或纵梁延伸至地面；顶面、总外高、外占位不变。
- `bottomDeck` 可省略，旧文件保持原部件、原几何、原统计与原结构核对值。显式 `runners` 规范化为省略值；未知结构、实心或四角脚底座搭配无底板参数拒绝导入。
- 无底板的实测底板厚度必须为 0；带底板必须为正。切换底板结构时，保留其他实测数值，清空实测来源和版本以提醒重测；恢复底板时厚度回到未核验的比例示意值。额定结构核对值绑定底部结构，改变后旧核验失效。
- 自重、额定承重由用户重新确认，不按删板自动推算重量或材料强度。底座完整外包络仍保留，板缝和底部孔隙不用于塞货。单面型不表示可翻面承重或可上货架。
- 主三维、回退投影、独立整托、相同包装的质量重心估计、JSON／CSV／工作区及报告使用共同部件数据；外观材质仍不替代受力资料。具体叉车动作不开发。

## 验证

旧输入及备份兼容、两种底座有无实测、部件落地且不重叠越界、顶部不变、旋转与孤立查看、同单箱数／重量守恒、完整占位、坏文件拒绝、切换后来源失效、结构核对值失效，以及预览控件的中英文、禁用和非适用状态。发布后双站原生恢复、结构选择、下载一致性、固定基准与默认草稿恢复另留证据。
