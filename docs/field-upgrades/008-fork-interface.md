# 计划 008 叉孔及实测结构

基线 v0.34.1，GitHub 1c437837fbadd19fbb342534a187b60b7fed1571。本阶段实现包装底座与双叉接口的独立几何预检，保留 U03、U05 的后续工作，不启用设备自动搬运或木箱自动叠放。

## 范围

- 可选填写面板、底板、横担厚度、单板宽度及支承块长宽，保留规则等距排布；渲染、投影、承压结构与叉孔检查共用 packagingParts。旧文件保留原比例结构，标记通用示意，不能标为实测。
- 从实际部件投影求长、宽方向的贯通矩形净孔；不把孔洞当补货空间。部分插深按输入的两根矩形叉具包络逐一检查，不凭孔口宽度推定内部畅通。
- 保存进叉面、叉宽厚长、中心间距、横向中心、底部高度、插深、叉尖余量、检查间隙及完全抽叉后的额外净距。0 表示相关叉具资料未填写，不代入示例设备。
- 逐托检查局部部件与叉具的插入／抽出直线扫掠，并按实际 LWH／WLH 朝向映射到装柜坐标，检查周围货物、其他整托、固定区域及柜壁。柜门外空间只在后门通过范围内放行；只打托的编组坐标不作为现场空间。
- 结构、叉具资料来源及版本单独填写，人工核对绑定实际几何与参数；修改后旧核对标记失效。静载、动载和货架载荷分别保存，不能复制现有求解载重上限冒充三类额定值。叉车本体、额定能力、起升、转弯、坡度、轮压、受力和现场状态仍为未核验。
- 不提供采用／放行按钮，不自动改变货物数量、箱位、重量或运输固定状态。局部几何通过只说明所输入矩形叉具包络没有与已建模区域相交。

## 一致性与交付

实测底座字段随模板、各包装规格、工作区和完整结果保存；旧文件兼容。底座改变使木箱结构核对标记失效。CSV、客户／离线报告及 PDF 保留来源和范围。逐托 JSON 在导出时重新计算，记录方案版本、输入和阻挡 ID，不能导入为采用方案。

## 验收

覆盖旧比例模型一致、测量边界、纵梁两向差异、墩式四向、实心无孔、孔口后方受阻、宽厚／间距／插深／叉尖余量、抽叉扫掠、旋转映射、邻托／箱／固定区域／柜壁与后门、缺资料／过期核对、三类载荷不混用、订单及重量守恒、备份篡改与多规格、中英文、无效数字和报告同源。

完整执行 npm run build:pages；同步 GitHub、Pages 与 Vercel，并实际核对两站版本与关键流程。真实 GPU 仍须硬件验收。

## 参考范围

HSE [Pallet safety PM15](https://www.hse.gov.uk/pubns/pm15.pdf) 第 2 至 4 页分别列出货载分布、搬运方式、进叉方向、堆叠及货架条件。因此本阶段分别记录这些条件，不把同一个额定值适用于所有工况，也不从材料或外观推算能力。该文件是范围参考，本软件没有实现其全部建议或认证检查。
