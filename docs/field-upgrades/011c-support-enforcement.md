# 计划 011C 长件支承约束接入与局部重排

状态：TODO。基线 v0.40.0。011B 已完成原始资料与独立预检，具体叉车操作已排除。

## 实施顺序

先将来源齐全、与箱规绑定且适用当前底面的明确几何限制接入自动候选和手动箱位采用校验；主三维、托内移动、层型应用、撤销重做及备份恢复使用同一约束。失败整次回退，完整套装和锁定其他整托保持不动。缺数据保留未核验，不用新规则绕过既有承托面积和重量约束。

再处理实际垫木／支架／底座的接触位置、厚度及重量，避免重复计入；支持自定义支承面和禁接触区，逐步增加多边形／孔洞接触。确认几何及资料边界后，在锁定其余整托条件下局部重排，解释没有可用位置的限制原因。

## 验收

长箱跨两托、两端支承、中部缺口、支承带错位、端部超限、横转／翻转、不同托高、真实垫木厚重、多箱套装、层型复制、未核验资料、资料变更、备份恢复、中英文及交付一致性。小规模基准给出已知可行／不可行位置；较大订单记录搜索预算和未检区域，不能把预算耗尽当作不可装证明。材料强度、真实 GPU 和现场试装另列。
