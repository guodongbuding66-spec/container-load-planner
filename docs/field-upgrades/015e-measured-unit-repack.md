# 015E 实测整托包络采用与底置重排

目标版本：v0.61.0。U17 继续 PARTIAL；本文件界定本阶段软件和验收边界。

## 目标

把已登记交付版本的逐托实测资料用于真实装载占位，生成可预览、可明确采用的新方案。保留物理底座、围护结构、托内箱位、箱托编号、套装关系、原朝向和计划重量。实测突出量不是底座或托内可用空间，不以扩大木箱内部尺寸代替公差。

## 首阶段范围

- 最多 60 个完整预打托单元，全部底置、无锁定、当前方案没有散箱，每托均有当前版本对应的实测来源与日期。
- 使用原外形与实测外包络的并集，较小读数不能缩小既有占位。向柜头及左侧的突出量在重新放置底座时保留；不旋转整托，不调整托内货物，不自动补货或丢弃装不下的整托。
- 附件重量必须为零或明确已经包含在计划重量中。未采用的附件增重阻止尺寸采用，不重复加重或假定其位置、重心和强度。
- 后台线程执行有界搜索，15 秒超时，可取消。源方案、实测记录、输入或阻塞状态改变，预览立即失效，忽略迟到结果。未找到保留全部整托的候选时保留原方案，不能断言物理无解。
- 采用操作沿用已装现场记录保护和既有交付版本登记、备份机制，生成新修订。旧工程资料仍属于旧修订，不自动认证为新测量。

## 共同几何与持久化

逐托保存带版本的实测占位及来源，物理底座保持原值。托内几何和朝向的变化检测值绑定相对坐标、箱号、尺寸、重量与套装关系；整托平移仍有效，托内变化、旋转或编辑中删除占位均拒绝。此检测值不是认证签名或实物证明。

统一用于独立碰撞／边界／门洞／保护间隙校验、其他整托和散箱检查、柜内区域、空隙分析、装卸包络、包络占用率，以及独立整托查看。物理重量、几何重心和材料体积不因空隙预留而增加。

三维及真实坐标回退图用棕色包络标识，清单和属性区分物理底座与实测装载占位。工作区和方案 JSON 保留资料；CSV 增加独立实测包络 JSON 列；PDF、HTML 报告及逐托标签注明采用尺寸和来源，已有列及原标称方案保持兼容。

整单重新计算使用原标称输入，另建方案，不自动重用旧测量。需要改变托内货物、朝向或再次测量时，恢复采用前的工作区备份。新的包络不是可承重实体，首阶段不允许整托上架叠放。

## 验收

覆盖保守并集、两侧突出、同规格多托、非 1:1 套装、数量与重量守恒、锁定／旧版本／缺资料／未计重附件拒绝、搜索失败不减量、来源转义、线程取消／超时／迟到消息、备份恢复、占位删除和几何篡改拒绝、原生导出及双站实测。最终测试数量、部署及证据写入对应升级记录。

## 后续

散箱与已装锁定单元参与局部重排、跨托／跨柜联合搜索、旋转后实测追踪、按单元保留未入柜结果、附件增重正式采用及其重心、更精细真实形体和复杂承托继续未完成。真实 GPU、多浏览器、材料强度及工厂实装保持独立 PENDING；具体叉车动作 EXCLUDED。
