# 计划 006 多规格包装自动比选与尾数优选

基线 v0.32.0 / GitHub 6c5efd91a41f18c2edaeccd708a849f3dca6cf37。

新增可选 compact 模式。每轮对当前可用、SKU/套装适配且满足内高、载重、方向和门洞的规格分别实际打托；按必装与优先级货量逐组比较。货量等效后依次优先完整外包络较小、占地较小、自重较轻；完全相同保留列表顺序。默认 ordered 模式及旧工作区保持原顺序行为。

范围：打托输入及解析、palletize 候选选择、打托元数据、配置和清单说明、工作区/CSV 比选记录及测试。保留全部独立校验；不实现全局最少柜数、费用优化，不改变纸箱、套装、木箱底置与承托规则。候选只影响选择，未选规格不扣库存。

验收：大包装优先满载、尾数改选小规格；高优先货量不因尺寸减小而让位；SKU限制、整套比例、库存、门洞、保护间隙和载重回归；两模式和两个算法；备份恢复同一模式和说明，篡改模式或选择身份拒绝；托内编辑后移除不再适用的生成记录。完整验证与两站发布。

启用边界：这是逐托局部启发式，不保证最少托数、包装费或运费；车辆后续重排可能产生尾货。独立打托、装柜、数量、自重、包装外形继续使用相同校验。
