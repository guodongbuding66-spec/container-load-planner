# 计划 010B 连贯搬运动作与承托切换

状态：TODO，接续 v0.37.0 独立单段预检。用户已授权按台账继续实现、测试并同步既有 GitHub 和两站。

## 目标

把独立单轴动作组成有明确先后、设备朝向、货叉与货物连接关系、承托状态的任务。以固定朝向、平整地面为首个连贯流程，转弯及坡道独立扩展。

## 首批范围

1. 为设备、现场及动作任务建立稳定版本契约；完整工作区、双策略、独立报告采用同一任务。恢复时重算并校验，不保存可直接复用的通过状态。
2. 提供接近、进叉、起升、直线过门、落位、抽叉、退出步骤；逐步核对起终姿态连续，明确尚未执行或不支持的转向。
3. 进叉达到有效插深后才能随托搬运；落位后需明确有效承托，才允许解除连接抽叉；不能把瞬移、悬空或载货时抽叉当可行流程。
4. 复用连续扫掠及实际底座部件；车体留在地面，门架使用有来源的全动作占用包络。不同步骤不得静默跳过货物、后装附件或安装预留。
5. 所有失败记录步骤 ID、部件与障碍 ID；前步失败或资料缺失时后步不得自动放行。几何、运动学、设备能力、支承与现场分别显示。

## 验收

不连续相邻步骤、缺步骤、起升未进叉、载货抽叉、无承托解联、目标托与邻货、叉尖超出、门外不足、门框门槛、起升后高度、模板或包装变更、未知额定、恢复篡改、双策略及订单库存守恒、中英文、实际两站流程。执行 npm run build:pages，核对 GitHub CI 与正式部署；真实 GPU 与现场证据单列。

## 后续边界

转弯需先定义参考点、转向约束、连续保守覆盖及误差；不能用填写转弯半径或稀疏采样替代。搜索预算耗尽只报告当前范围未找到。额定能力与支承资料未齐不能推断；安装／拆除材料须独立任务。
