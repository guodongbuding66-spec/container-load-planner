# 计划 011D 托内实心支承件

状态：首阶段软件完成，属于 011C 的托内实物接触延伸。版本 v0.43.0；U04／U06／U07 整体仍 PARTIAL。具体叉车操作仍 EXCLUDED。

## 本阶段范围

在每种预打托包装规格中增加最多 12 件实心、平顶、直接贴合底座的支承块／垫木。每行单件，录入原始托盘坐标 X/Y、长宽厚度、新增自重、上方静载上限、实测来源和版本。厚度占用原有货物限高，不额外抬高允许上限。支承件底面须完全接触实际底座面板；不接受相交、悬空、越过木箱内壁或跨板缝架空。

这些部件属于包装规格，不作为订单 SKU，也不计入套装箱数。当前需要在包装配置中修改后重新打托；不提供方案内单独拖动垫木的入口。已有托内货物编辑仍逐次执行统一校验。

## 重量与空间契约

1. 原 `config.weight` 含原底座、围板和箱盖，保持旧文件含义。新支承件的 `weightKg` 另填，未知重量必须补全或明确确认零后才能计算；不再重复加进原包装自重。
2. 完整包装自重 = 原包装自重 + 支承件自重；`PlacedPallet.weight` 保存此合计。底座额定载荷承受货物加新增支承件，货物可用额定载荷相应扣减。整托与柜内总重各计一次。
3. 体积 = 原底座／围护预留 + 实心支承件 + 货物；部件不得重叠，底座板缝与框架内部空间不因此填实。整托外包络包括没有被货物覆盖的支承件。
4. 支承静载上限指其上方载荷，不含自身重量。null 是未知，0 是禁止承载；填入的数值即使缺来源仍执行上限，资料不足保持未核验。
5. 按接触面积分配并传递全部上层货物静载，不计算梁弯曲、刚度、固定强度、柜底局压或运输动态。普通板式底座缺实测来源版本时，相关支承证据保持未核验。
6. 新支承件质量按实物位置参与计划重心和长向分区重量；旧底座／围护质量分布仍采用已有均匀材料估计，不当作实测重心。

## 同源性与保护

- 主打托候选、长件支承带／悬跨／悬挑、独立几何和承重校验、货物层级、归属、托内编辑、空隙试放及恢复使用同一支承面。
- 保留原承托面积、允许朝向、底置、层数、整套原子回退、包装库存和其他锁定整托；不能通过支承声明放宽这些条件。
- 支承件随整托移动和水平旋转。新增 `PlacedPallet.quarterTurns` 保留四个方向；旧文件未填时仍按 LWH=0、WLH=1 解释。底座部件、支承件、坐标、反向托内坐标、质量中心和导出同步变换。
- 中英文设置、真实部件三维／坐标回退显示、清单、静载状态、附件专用 CSV、坐标 CSV、客户／离线报告、分页 PDF 和双策略备份保存同一资料。
- 备份恢复重新核对当前包装规格、物理质量、四向记录和箱位，旧通过标记不能授权新位置。原有整柜附件与托内附件分别计入，不能重复录入同一件材料。

## 尚未完成

- 跨板缝、架空、叠垫木、空心支架、任意曲面／孔洞／多边形接触、自定义受力面及禁接触面待实现。
- 改单托支承而不重新生成规格、保留其他锁定整托的局部自动重排、结构强度及现场试装待完成。
- 真实 GPU／多浏览器硬件验收仍 PENDING，不以软件渲染器或 SVG 代替。
