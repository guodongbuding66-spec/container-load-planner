# v0.79.0 测量、跨柜实物身份与现场交付（第 3／5 轮）

2026-11-06（Asia/Shanghai）。[五轮交付计划](five-release-plan.md) · [剩余项目](field-upgrades/unfinished-roadmap.md)

- 多柜面板可登记单柜交付版本，并使用跨柜唯一的箱托编号导出实物台账。已有二维码能定位到对应柜、交付版本和箱托，登记仍需明确确认。
- 多柜交接 JSON 合并同版本现场事件、逐件核重和作业记录，并保留原多柜快照。旧的多柜 JSON、单柜事件、核重和作业备份格式继续可用。
- 支持已登记候选柜型换柜和排除一个缺货包装规格的余货试算。保留包含已登记、锁定或实测柜的连续前缀。逐订单行数量减少、库存或几何校验失败时禁止采用。包装缺货只约束本次试算，主数据仍按原报价和库存配置。
- 逐件核重以完整预打托、散箱、独立底座和实体附件作为互不重叠的计量范围。缺读数或同件并行读数冲突时只汇总已核重量。重称保留旧记录和替代关系。
- 两箱间距可以求七种规则实体完整表面的最短净距。测量 v3 备份可重新计算见证点，继续读取旧 v1、v2。新增可复制和浏览器打印的文字 HTML。
- 当前交付版本增加居中唛头的实际平面适配与保守读标通道核对。防潮用量根据录入湿负荷、安全系数和已明确匹配的材料额定吸湿量计算。作业清单继续核对安装和封柜的前置依赖。

工程边界包括平面规则外形、实际测量来源和柜内可用空间。曲面与复杂导入模型的最短净距、真实秤具、扫码硬件、工厂试装、温湿度与凝露的现场证据仍待独立验收。已登记柜整柜保留，未登记余货可重排。跨设备通过手动文件交接。
