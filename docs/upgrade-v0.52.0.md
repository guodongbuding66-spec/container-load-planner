## 新增完整装载实称

交付面板新增“计划重量与实际核重”。计划货物毛重、另计托盘／木箱和固定／防潮材料分别核对；不再把计算值混同实称。录入整柜总重减皮重或直接实称净载荷，必填来源、磅单及时间并确认完整范围。复称全部保留，显示差额和净载重超限。

记录绑定已登记的当前交付版本；旧版、复制计划、重复编号冲突及非法数据不会替换当前记录。JSON、文本备用和 CSV 独立导出，可同版本防重合并；损坏缓存不覆盖，存储失败明确提示外部备份，本页暂存防止面板切换后丢失。详见 [016A](field-upgrades/016a-weighing.md)。
