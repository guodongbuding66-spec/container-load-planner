# v0.40.0 长条箱承托资料与独立几何预检

日期：2026-10-18。基线 GitHub `27b4dde5510fa6e618a52281a624187015eae7e9`、树 `3c6a4bed8044855b2e48b886e883be0a44885078`，引擎 v0.39.0。

## 本轮范围

按 [011B](field-upgrades/011b-long-cargo-support.md) 先完成资料和独立检查，不模拟具体叉车装卸。本轮不把独立检查当作主求解器的候选约束，不自动重排、增添支架或放宽原有承托面积规则，也不据此授权箱位采用。输入限制不符合时，在托内草稿、主方案复核和交付报告中明确显示。

货物设置新增可选“长条箱承托与悬跨资料”：按原始箱规 L／W／H 绑定，指定原始 H− 底面；沿 L 或 W 定义最多 12 条必须接触的支承带，每条横跨另一方向的整个宽度。填写每带最小接触比例、最大中部悬跨和每端最大悬挑、资料来源与版本。所有值固定为 mm，不随货物录入单位变动。0 是明确上限，留空是未知。

支承带是必须满足的区域；带外接触允许存在，但不抵扣指定带缺口。本阶段没有“仅允许在这些区域施压”的禁接触区域模型。箱规变化后旧资料不缩放，显示未核验；显式重新绑定会清空来源、版本和跨度上限并重置支承带，要求重新填写。

## 检查口径

- 首阶段仅普通长方体箱规，检查指定底面是否朝下；按同一真实旋转和轴符号，将接触区转换回原始箱体坐标。水平四向旋转保留资料含义，侧翻或翻底不沿用旧面。
- 柜底为平面；下方长方体提供实际相交的顶面；托盘采用同一包装模型的顶层面板部件，板缝不填实。不把障碍、禁占区、围板或更高处部件当作当前接触面。
- 矩形接触取精确并集，重复或重叠接触不重复计面积。每条支承带单独求接触比例；沿检查轴扫描横向接触比例达标的连续区段，分别给出中部最大悬跨及首尾悬挑。
- 未记录底座完整实测来源、非矩形或未知接触、公差保守方案、改过箱规、缺少上限或来源版本不能视为符合；已知明确的几何违规优先显示不符合，无法可靠判断接触时显示未核验。每箱最多检查 500 个同层候选，整次接触候选预算 100,000，跳过时明确标为未核验。
- “符合输入几何限制”只表示比较结果。方案承重项仍保持未核验，材料抗弯、抗倒、局部压强、连接件及运输动态强度均未证明。

## 接入与交付

主方案及完整托内编辑草稿使用同一 `inspectLongSupport`，编辑、层型复用或撤销后随当前箱位重新检查。侧栏观看筛选不影响检查范围。页面最多列前 80 箱，报告保留全部已记录箱位。

资料随本机草稿、工作区备份、方案 JSON 和坐标 CSV 保存；CSV／Excel 产品导入支持 `longSupport` JSON 列，内部尺寸始终 mm。备份恢复仅保存原始资料，独立检查重新生成，不信任外部通过标记。客户报告、离线作业及 PDF 包含当前预检结果和资料口径，工作区和客户报告附完整关联资料。
