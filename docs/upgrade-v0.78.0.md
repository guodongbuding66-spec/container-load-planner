# v0.78.0 包装、几何与工程约束（第 2／5 轮）

2026-11-05（Asia/Shanghai）。[五轮交付计划](five-release-plan.md) · [工程与布局契约](field-upgrades/018-engineering-layouts.md)

- 新增原柜整托／木箱补入。保留原位箱托、已装柜前缀和散箱预留，核对实际新增包装库存、进柜路径和打托费用。
