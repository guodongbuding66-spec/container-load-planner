# CargoFit v1.5.0 升级记录

发布日期：2026-11-28

## 核心升级项

### 1. D13（P1）：静力学轴重分配与左右偏载估算器
- 新增 `lib/packing/axle-load-estimator.ts`，基于真实 3D 货载重心 `(CoG X, CoG Y)` 计算前后轴静力学杠杆货载分配与左右横向偏载率：
  - 内置 3 类标准车型参考模型：集装箱骨架半挂车（牵引销 + 后三联轴参考）、标准半挂厢车（牵引销 + 后双联轴参考）、单体厢式货车（前单轴 + 后驱动轴参考）。
  - 实时检测前/后轴超参考限值与左右横向偏移（>12%）风险，并显式标注静力学估算边界（不含车头/车厢自重与制动惯性）。
- 集成至步骤 7「工程分析与多目标决策」面板，支持即时切换车型轴距模型并查看前后轴载荷分布条。

### 2. D17（P2）：现场作业端 `/crew` 离线扫码枪核销与异常差异登记闭环
- 新增 `lib/packing/crew-scanner.ts` 并集成至 `app/crew/page.tsx`：
  - 兼容蓝牙/USB 扫码枪（键盘模拟 + `Enter` 自动提交）与手机端手动 `+1` 核销，自动清洗 `SKU:` / `ITEM:` / `BARCODE:` 前缀，内置超扫防呆拦截与一键撤销。
  - 新增现场异常差异登记（外箱破损 / 少货短装 / 临时换位 / 尺寸偏差 / 超重预警），离线持久化至浏览器本地缓存。
  - 支持一键导出 `CargoFit_ScanAudit_*.csv`，并自动将 `scan-audit.csv` 与 `discrepancies.json` 打包进「一键打包照片 ZIP」。

### 3. 质量与回归保障
- 新增 `lib/packing/v15-features.test.ts`（6 项单元测试），保持 37 种既有海运/陆运/航空 ULD 空间预设及全部既有测试零回归。
