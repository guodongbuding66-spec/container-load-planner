# v0.29.0 托内编辑与订单余量

实施基线：`46e3ad9fd459664285ab8ece4b22ab7a65807720`。日期：2026-10-15。

## 本轮可用流程

在“只打托不装箱”或“先打托后装箱”的完整方案中，打开打托清单的“查看／编辑托内货物”。启用编辑后可多选货物，验证移动、水平转 90°，按实际托内底高复制层，从订单余量增加一箱／整套，退回余量，或向另一张未锁定托盘转移。

单托窗口始终从完整方案生成预览。输入框的 X/Y 沿包装原始长宽，Z=0 为托面；三维及降级俯视图的移动偏移经过局部／柜内坐标变换后提交。支持 LWH/WLH 和有符号的非对称形体方向，不改变原包装结构或尺寸。

点击“采用托内调整”前，主方案及其导出保持原版本。取消、关闭或放弃会丢弃草稿；采用完整草稿后同步整柜清单、重量、体积利用率、重心和导出。复用原编辑器的 20 步历史，撤销和重做同时恢复箱位及派生的订单余量。

## 数量、身份与物理规则

- 增加和复制只能占用原始订单的待分配数量。删除整套退回所有组成箱；跨托转移不改变订单池数量。SKU 规格不变，混托、适用 SKU 和库存条件继续检查。
- 层按托内底部的物理高度分组，不使用全柜层号。若一层含有跨层套装，复制时连同整套组件处理；候选不满足限高、承托、碰撞或承重时全部回退。
- 移动和转移保留箱体 ID、套号和套内序号。复制／新增生成新箱体 ID、新套号；不复用既有追踪 ID。编辑版本允许删除后的稀疏套号，其他托盘的既有身份保持不变。未编辑的旧方案继续执行连续套号规则。
- 空托仍是实际包装：保留托盘／木箱模型、预留空间和自重，不把清空货物等同于移除包装。当前不增删包装规格、不自动新建托盘。
- 锁定整托时，其坐标、货物身份及内容保持不变；主三维编辑同样遵守锁定。当前托盘可明确解除锁定。锁定不代表材料强度已经核验。
- 事务先重建承托层，再调用原完整快照校验器和整托校验。原始输入和已采用方案不被原地修改；异常候选不进入历史。原始箱体承重、实体碰撞、套装完整性、包装净空、库存与整托支撑条件保持。
- 备份保留编辑版本与整托锁定，并重新计算统计和执行校验。采用后清除失效的策略对比。现场进度指纹覆盖完整版本数据，旧进度不能用于新的托内版本。
