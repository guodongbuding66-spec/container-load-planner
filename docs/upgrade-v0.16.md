# CargoFit 0.16 — 完整工作流程升级

本版本延续 0.15 的剩余容积、项目归档、手动校验、承重、多柜及现场执行基础，补齐流程衔接。

| 用户需求 | 实际入口及行为 |
| --- | --- |
| 完整方案保存与恢复 | 方案库支持保存新版本、另存、复制、导出／导入；文件保存输入、两种独立算法坐标、包装来源和锁定标记。恢复重新校验全部坐标，保留单品计划上限，输入过期时不夹带旧结果。 |
| 可控计算 | 拼柜先显示已校验的首轮方案，再完成搜索；可以停止保留结果。手动方案下可继续优化 15／35／60 秒，停止后保留当前最优可行解，再明确采用。 |
| 缺装解释 | 显示门洞、方向／柜内尺寸、载重、容积、套装约束、层数及承重设置；没有确定证据时显示搜索尚未找到。定位图高亮 SKU，其他货物保留灰色轮廓。 |
| 人工微调 | 平面拖动、XYZ 移动、单箱／同套水平旋转、30 mm 吸附、撤销重做、锁定。采用后指标、坐标、视图、导出统一。 |
| 锁定后重排 | 固定锁定箱、递归支撑依赖和同一完整套装，重排其余空间；拒绝数量或装载得分退步，同等装载量偏好执行复杂度更低的结果。 |
| 可量化承重 | 累计上压、原始长／宽／高成为竖直方向时的承重上限、上方 SKU 白名单；约束进入求解与独立校验。参数不全显示承重未核验。 |
| 多柜订单与费用 | 对照统一柜型、混合柜型及最多前四种柜型的两两组合；保留每柜完整套装。检查尾一／二柜能否合并或换为更便宜柜型。费用按每柜实际占用体积分摊。 |
| 配比增补 | 用户设置 0–20% 上浮范围，默认 0。仅在已选柜数和费用内提出完整套装追加量；不减少原订单交付，也不自动修改订单。 |
| 仓库执行 | 按箱或连续区块／SKU确认；手机全屏、当前位置、朝向、SKU剩余量。本机保存进度，离线 HTML 无网络依赖，可导出／导入现场进度。 |
| 包装与实装库 | 包装版本、生效日、变更说明；实装数量、柜内实测尺寸、照片、耗时、偏差原因；完整导出／追加导入。 |
| 独立验收 | 新记录默认验收集；校准只使用同包装、柜尺寸、计算约束的校准集。修正系数用于报价参考，不伪造几何方案。 |
| 客户报告 | 中文／英文 HTML，含三视图、客户订单、需求与余货、剩余容积、费用分摊、承重状态；浏览器打印为 PDF。 |
| 云端项目与分享 | 使用外贸 OS 账号和团队权限；版本追加保存、跨设备恢复。创建只读链接与二维码，有效期 1／7／30 天，可撤销。 |
| 外贸 OS 双向集成 | 读取真实订单及 SKU 包装，cm 转 mm、订单套数转箱数；已校验结果转 cm 写回 OS 装柜方案。服务端验证 SKU、包装、订单的租户归属。 |

## 使用顺序

1. 输入全部箱规并统一计算，检查剩余容量及缺装原因。
2. 需要时编辑承重规则，或在手动方案里移动／锁定箱体并继续优化，再采用。
3. 保存项目版本；按需生成多柜对照、客户报告和离线现场指导书。
4. 云端操作从“云端工作区、只读分享与外贸 OS”展开，连接自己的 OS 账号。点击保存才上传，实装照片不会自动上传。

## 边界

- 多柜组合、尾柜和局部重排属于有限搜索，不能声称全局最少柜数／最低费用。
- 剩余总容积包含碎片空隙；不保证存在同体积的整块可用空间。
- 路径检查只检查固定最终姿态沿柜长直线送入，需抬升／倾斜的箱位标为待复核，不模拟人员、叉车的完整运动。
- 静态承重按接触面积向下累计分配，依赖用户提供的包装承重数据，不替代包装测试或运输动力学分析。
- 云端沿用 OS 的 D1、会话及权限，不新增匿名写入口。单个云版本含封装请求不超过 1 MB，文件备份上限 5 MB；大型方案用文件移交。
- 分享是持链接只读访问，可下载快照。撤销和过期阻止后续访问，不能收回已下载副本。
- 本机数据不能自动跨域同步；跨备用网址用工作区文件或团队云版本恢复。

## 校验

新增回归覆盖锁定依赖、成套身份、朝向承重、双算法归档、过期结果排除、计划上限、尾柜合并、费用守恒、配比增补、离线脚本转义、OS 单位转换、校准验收隔离。
云端集成测试使用真实身份验证模块与隔离 SQLite，覆盖权限、CSRF、租户隔离、版本追加、只读令牌过期和撤销、请求大小、SKU／包装／订单引用归属。
