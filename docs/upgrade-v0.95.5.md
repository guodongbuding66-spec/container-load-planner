# CargoFit v0.95.5 — 多柜工具与包装规则布局

本轮承接 v0.95.3 评测的两个布局问题：多柜工具内层重复边框，以及第四步三个规则标题的折叠态高度不一致。

## 多柜工具

保留工具外层边界和输入控件的边界，运费与包装报价、包装单价、可用柜型与运费以标题、留白及分隔线区分。包装报价的禁用状态、未报价与免费报价的区别不变；优化、库存、费用计算和备份格式不变。

柜型选择新增可访问的分组标题。自动优化与现场交接区域复用同一层级规则，窄屏柜型设置采用单列，并保留两列数值输入。

## 第四步包装规则

适用货物、整托与散箱混装、已采用规格的整托堆叠共用相同的 disclosure 标题：箭头、规则名称和状态按同一网格对齐。桌面标题预留两行名称与一行状态；手机按顺序改为单列。各栏原生 details 仍独立开合，键盘焦点可见，展开内容不拉长相邻折叠栏。

散装数量仍在第三步录入，当前规则栏只说明现有分配；没有额外引入会影响计算的数据副本。

## 验证记录

- `npm run verify` 完整通过：190 个测试文件、2305 项单元测试、21 项页面检查；类型与 lint 无错误，两个既有 lint 警告保留。
- 浏览器检查了 1440×900、1280×800、768×1024、390×844 的规则区布局；中英文桌面标题均为 88 px，窄屏标题为 64 px。展开适用货物后，其他两栏仍保持折叠高度。键盘 Enter 可独立开合并显示焦点。
- 中英文多柜报价区、窄屏柜型设置未发生页面横向溢出。未报价时包装单价禁用，明确报价后 0 单价可用；切换币种保留重新录入提示。
- 浏览器未启用 WebGL；本轮验证只针对布局、原生控件交互及降级预览，不作为硬件画质与性能验收。
- 最终预览与正式发布记录在 PR 中补充。
