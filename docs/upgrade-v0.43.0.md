# v0.43.0 预打托实心支承件

日期：2026-10-19。基线 GitHub `fa4f9d6fe7ffb2d5a5c1b6fe486bf013b9a13563`，源树 `4718eea104ea28040a51cb3ddfa9dd950f8647e7`。

v0.42.0 的实心支承件只能固定在柜底。本轮增加包装规格内的实心平顶垫木／支承块：随整托移动旋转，厚度真实占用托内净高，新增自重与原包装自重分开录入，累计上压参与候选筛选和独立校验。

## 完成内容

- 每种包装规格可录入最多 12 个直接贴合底座的实心部件。实际板缝、木箱内壁、相交、尺寸、净高、重量和静载资料均独立检查；不把跨板缝或空心框架包络当作实心支承。
- 原包装自重保持旧字段含义；新增部件质量另填，合计进入整托包装自重与柜内载重。底座额定载荷同时扣除新增支承质量，体积各计一次。偏置垫木按真实位置参与重心和分区重量。
- 共享支承面用于自动打托、长件几何预检、独立位置及累计静载、托内编辑、层级和托盘归属、空隙试放、最终采用与恢复。完整套装失败整批回退，失败规格可尝试下一种；其他锁定整托不被改变。
- 四个水平旋转方向保存为 `quarterTurns`，处理非对称支承件；旧文件 LWH／WLH 含义兼容。托内坐标往返、真实模型部件、投影、重心和坐标导出使用同一变换。
- 中英文设置与结果面板、专用支承 CSV、坐标 CSV、客户／离线报告、分页 PDF 和双策略备份更新。缺上限或来源版本保持未核验，0 明确禁止承载；当前包装规则改变后不能沿用旧文件的通过状态。

## 边界

只打托／先打托后装柜使用该功能；带支承件的整托先按单层底置，上压为 0。部件配置改变需要重新打托。底层自动铺托盘、叠垫木、跨板缝、空心框架、复杂接触面、单托支承单独修改和局部自动重排仍待实现。静载按接触面积分配，不核验材料抗弯、刚度、柜底局压、运输固定或动态强度。具体叉车操作仍 EXCLUDED；真实 GPU、硬件多浏览器和现场试装仍 PENDING。

详细数据契约与后续缺口见 [011D](field-upgrades/011d-deck-supports.md) 和[未完成台账](field-upgrades/unfinished-roadmap.md)。
