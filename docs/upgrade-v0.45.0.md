# v0.45.0 木箱四角单列自动叠放

日期：2026-10-19。基线 GitHub `3ab2bc7c2fed853bf62ce66397341e8656671749`，源树 `e89f420b52d0de6086350ac4cd45deac2247c6d9`。

木箱额定资料新增独立的自动叠放启用项。显式启用并重新人工核对后，两套主算法可建立四角单列；旧文件和未启用／资料失效的木箱继续底置。

## 本轮完成

- 将既有四角实体路径接入候选筛选，逐层核对四脚接触、资料／朝向、累计顶载、每条路径完整毛重上界及各箱上方层数，最多 20 层；允许顶层额定层数为 1。
- 统一校验、采用、编辑与恢复使用同一列检查；修改上箱内容会重新核对所有下箱。内部纸箱承重与外部框架传力分开，质量及包装库存各计一次。
- 修复不同木箱内壁厚度导致的播放顺序风险，保持完整下箱内容先于上箱。恢复时额定资料和结构均与当前输入绑定。
- 主清单增加实际叠放静载表；热力图、数据复核、CSV、HTML、PDF 分别显示资料状态、实际状态、累计上压、每路径上界和下箱／层级。PDF 实际静载页按 8 箱分页。

完整契约、迁移和后续边界见 [012 阶段文档](field-upgrades/012-crate-auto-stack.md)。U08 保留 PARTIAL；具体叉车操作继续 EXCLUDED。真实 GPU、硬件多浏览器与现场试装仍 PENDING。
