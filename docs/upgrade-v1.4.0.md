# CargoFit v1.4.0 升级记录

发布日期：2026-11-28

## 核心升级项

### 1. D14（P1）：多卸货点 LIFO 顺序校验与逐站重心偏移审计
- 新增 `lib/packing/multi-stop-auditor.ts`：
  - 基于当前 3D 装载结果执行真实物理 LIFO（后装先卸，柜门位于 `L+`）校验，自动识别 **门向阻挡（door-path）** 与 **上方压顶阻挡（top-stack）** 两类违例。
  - 计算各卸货站次箱数、重量、体积、`X` 坐标区间、零翻倒直卸可达率（%）以及 **逐站卸货后的剩余重心纵向位置（CoG X%）**。
  - 支持一键导出多站点装卸顺序 CSV（`cargofit-multistop-lifo-*.csv`）。
- 集成至步骤 7「工程分析与多目标决策」面板，支持对当前方案中各 SKU 实时切换卸货站次（第 1–4 站）并即时重算阻挡与重心。

### 2. D15（P1）：3D 空隙扫描与充气袋／防倾倒加固耗材清单
- 新增 `lib/packing/securing-void-analyzer.ts`：
  - 沿集装箱长度方向按 1.2 m 工程区段扫描真实货箱 `Y` 投影区间，精确测算各区段横向净空隙与柜尾纵向余隙。
  - 自动区分 **80–450 mm 充气袋填充区**（按垛高区分 `900×1200 mm` / `1000×1800 mm` 规格）、**>450 mm 横向挡木／撑杆加固区** 及 **尾门防倾倒挡杆与交叉绑带区**。
  - 附带明确工程边界声明，并支持一键导出加固耗材清单 JSON（`cargofit-securing-plan-*.json`）。

### 3. 质量与回归保障
- 新增 `lib/packing/v14-features.test.ts`（6 项单元测试与真实求解器集成测试）。
- 保持既有全部 222 组单元测试与 21 项渲染测试零回归。
