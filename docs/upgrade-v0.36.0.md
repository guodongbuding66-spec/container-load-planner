# v0.36.0 整柜附件与固定预留

日期：2026 年 10 月 16 日。基线 v0.35.0，GitHub 781a96828db230ff6f6e235864e8642e2eafece0。范围见[阶段 009](field-upgrades/009-container-accessories.md)，剩余工作见[Markdown 台账](field-upgrades/unfinished-roadmap.md)。

## 本轮完成

装载配置新增“整柜附件与固定预留”。支持垫木／挡木、充气袋、绑带、挡杆／支架、防潮附件及其他材料。实体材料与安装空间分别录入；每行保存整体包络、数量、单件计划重量、来源、版本、关联产品、安装阶段、前置附件与安装／拆除备注。每行包络覆盖该行全部数量，分散位置须分条录入；不是绑带曲面、气袋变形或真实结构强度模型。

几何复用柜内区域：实际柜头、左壁、地板为原点，单位 mm；内部与箱位同一坐标换算。附件、安装预留与普通区域共同参与求解、独立校验、空隙、补货、路径、货叉扫掠和投影。重叠预留容积只扣一次，不提供承托，不加入货物箱数。沿用目前对只打托和自动铺底层托盘的明确限制。

附件计划重量以数量乘单件重量计算，独立于货物与托盘自重，各计一次。未填写重量不能计算，明确确认零重量后才保存为零；安装空间始终无重量。两套算法、单品倒推、整托入柜、编辑及恢复、剩余载重、重心和分区重量使用相同统计。位于安全间隙内的材料不因占位裁剪丢失重量。材料重心暂按整行包络中心、分区按跨区范围分配；属于计划估算，不是实称或局部地板受力验证。已计入箱体或托盘自重的材料不要再次录入。

安装依赖拒绝缺失引用、循环及装货前依赖装货后的矛盾。清单按拓扑顺序显示最早装箱步骤参考；关联产品未全部装入时，提示沿依赖链传递。未关联产品的后装材料以全部装箱步骤结束为参考。删除附件同时删除其他附件指向它的依赖引用。草稿允许保留未完成重量及依赖错误以便修正，正式求解和导入仍严格检查。

## 保存与交付

附件元数据随柜型、工作区与两个策略的完整结果保存。原有坐标 CSV 的柜内区域 JSON 保留附件全部字段，区域行重量记录实体材料合计计划重量，记录类型继续与货物分开。新增独立附件与安装清单 CSV，含方案 ID、引擎版本、位置、数量、重量、阶段、关联、依赖和来源备注。坐标 CSV 与包装比选、叉具资料和尺寸双方案叠加时保持行列一致，尺寸方案列仍位于最后。

结果页、客户报告、离线作业报告和 PDF 展示同源材料清单和核验范围。PDF 每页最多 6 行附件，长来源和备注截短；完整内容保留于工作区和附件 CSV。现场进度指纹包括附件资料，变更后不能复用旧版本的作业进度。全部附件重量从播放进度起点计入，空间始终预留，避免未展示后装材料时被再次补货占用。

## 验证与发布

新增 30 项专项测试；附件与既有区域相关测试合计 58 项通过。最终 `npm run build:pages` 包含 894 项单元测试（75 个文件）、21 项 HTML 检查、TypeScript、lint 零错误（3 条既有警告）及 Next 静态生产构建。生产提交及两站操作结果在交付时核对。

## 仍未完成

运输固定始终保留未核验；本轮不求绑扎力、角度、锚点、气袋压力、摩擦、制动、材料强度、安装可达或拆除动作。实体材料之间暂只记录保守包络，不证明其真实形体互不干涉。所有包络始终参与静态路径检查，后装材料也可能造成保守受阻，尚未实现按施工阶段动态增减障碍。关联使用产品 ID，尚未形成逐件材料扫码身份。

只打托没有整柜附件任务；自动铺底层托盘与区域的组合仍不支持。真实 GPU、多浏览器硬件验收、实称与现场试装仍为 PENDING。U04 保留 PARTIAL，下一阶段为 010 设备动作检查。
