## 每轮统一交付

1. 实现、独立校验、编辑／采用、备份和导出保持同源；保留已有默认订单和旧文件兼容。
2. 完整类型、lint、单元、HTML 及生产构建，新增有效／超限／缺资料／篡改／并发失效／数量和费用守恒回归。
3. 同步 GitHub，核对本地／远端树和 CI，分别发布并原生验收 Pages、Vercel；归档下载原件、截图和哈希。
4. 恢复验收前工作区，更新升级记录和同一份未完成清单；已完成内容保留版本、范围和证据。

## 不能用模拟结果核销的条件

- 原用户 596→16 的完整输入、真实工厂装柜／核重样本、包装额定／材料资料，须使用真实提供的数据。
- 真实 GPU、其他浏览器、相机扫码、打印和现场试装，须有对应设备操作证据。当前远程浏览器的二维降级不算 GPU 验收。
- 正式账号邮件和支付须有可用托管配置、商户资质及正式价格；沙箱通过不等于已经正式开通或收款。
- U03、U05 具体叉车操作维持 EXCLUDED，不重新加入五轮范围。
